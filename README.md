# 梦想小镇 · 河畔新生活

基于 `docs/01—09` 重新初始化的 Web 单机经营游戏。全屏等轴小镇、绘本风格建筑、可直接点击收获与建造的地图，支持桌面与手机操作。

## 运行

需要 Node.js 22.18+。

```sh
npm ci
npm run dev
```

开发地址默认 `http://localhost:5173`。

```sh
npm test       # 516 项纯模拟测试：经济、科技、道路、居民、灾害、存档迁移等
npm run scan   # 长时数值扫描：20 小时 × 四种情境，断言所有可观察量不越界
npm run build # TypeScript 检查、生产包与 PWA 离线缓存
npm run preview
```

PWA 离线缓存需要先联网访问一次生产预览或部署版本，开发模式不注册缓存。全部游戏资源随构建输出，不依赖远程字体或外部图片。

## 已实现

- Phaser 4 等轴世界：20 种生成建筑精灵、绘制麦田、46 × 46 两岸河谷、山区森林、六类写实居民、步行动画、收获标记与飘字。
- 居民、农业、工业、矿业四个分区，1,817 格可建设陆地、贯穿河流与两座桥梁；分区导航、全景地图和小地图定位。
- 免费搬迁、按分区整理工坊与可保存的位置还原；兼容当前重建版存档。
- 土路 → 石子路 → 青石板路，两点成路、差价升级与移除；建筑和道路互斥，铺设前整段校验。
- 居民沿四邻域路线绕开建筑、跨桥过河、优先走路面，建筑变化后重新规划；暂停与游戏速度同步。居民会区分状态：去工坊路上是搬运姿势，在工坊里是劳作姿势，其余时候散步——搬运与劳作取自 48 帧的动作图集，按各自的角色与朝向切换。
- 一键收取所有可入库的成熟产物，合并反馈，满仓批次保留。泥土、碎石、草丛地表与延伸背景，缩放时约束镜头范围。
- 拖动、滚轮与双指缩放，建造预览、地块验证、建筑点选、升级、拆除确认与材料回收。
- 21 种装饰：树木、喷泉、凉亭、长椅、花拱门，以及临街花箱、蔷薇花架、串灯花门、木栈道、滨河栏杆、遮阳伞座、垂柳、浮动码头、木箱堆、橡木酒桶、旧铁砧、彩旗招牌。全部不需要工人，提供环境加成，可免费搬迁与拆除。
- 会转的机械部件：风车叶片随磨坊开工转动、锯木厂锯轮、鱼塘水轮，以及铁匠锤与钓竿的摆动、矿场矿车。部件挂在建筑上各自的实测轴心，只在工坊真正生产时动——库存充足或暂停时当场停住。
- 住宅逐阶外观：林间小屋与田园小院各有三级独立美术，升级时当场换帧，不再是放大同一张图。其余建筑仍以单帧加缩放表示等级。
- 小麦 → 面粉 → 面包、木材/木板、石料与渔业，工人分配、原料消耗、仓库硬容量及售卖。
- 工业链：矿石 + 木炭 → 金属锭 → 工具；纺织链：小麦 → 饲料 → 羊毛 → 布料 → 衣物。
- 乳品与酿酒两条新产业链：饲料 → 鲜奶 → 奶酪；蜂场自产蜂蜜；葡萄 → 葡萄酒 → 陈年佳酿。共 6 座新工坊与 6 种新物资，「葡萄与酒」科技解锁后三位一体的葡萄酒线。加工越深越值钱：奶酪贵过鲜奶、陈年佳酿贵过葡萄酒。
- 8 项声望科技，永久解锁工坊、缩短生产时间、增加仓容与减轻税收惩罚。物资图标可追溯生产来源。
- 三项小镇荣誉（仓廪扩建 / 精工传承 / 安居名额），各八级：把攒下的声望换成永久容量、更快的生产或更多社区名额。声望不只是研究的手续费——研究合计只要 52 点，而任务、里程碑、成就、街区风格与邻居故事一直在发，荣誉是它的去处。一级比一级贵，效果刻意做小（满级容量 +32、生产 −12%、名额 +8），是缓解已有压力而不是取消它。八级而非四级是刻意的：声望的来源里，成就是封顶的（一次性），但**小镇等级每升一级就发 1 点、没有上限**。按 Daniel Cook 的 value chain 法则，source 必须由同等或更高力量的 sink 承接（恒定 < 线性 < 指数），而几何成本曲线正是那个「永远还有余量可吸收」的 sink——实测 120 小时后 sink/faucet = 0.994，在手声望稳定在个位数，且每条线还剩四级可攒。按小镇等级开放（5/6/7 级），因此不挑玩法。入口也有信号：声望够买时底部「科技」按钮出现角标计数，面板顶部台账同时报告研究进度与荣誉级数，「成长」角标报告有几个已完成未领取的目标（此前该角标恒为 0）；研究全部学完的那一刻，面板顶部会出现指向荣誉的提示条。价目与效果曲线不是手挑的数字，而是按 idle game 通行的成本模型导出的：`cost(n) = base × growth^n`（几何）配 `output(n) = value × n`（线性），base=6、growth=1.45 得出 6/9/13/18/27/38/56/81——逐级递减的性价比正是「何时停手」这个决策的来源。三条线强度经校准落在同一量级（13.3% / 13.6% / 22.9%），且各缓解不同瓶颈，所以不存在必然被跳过的那条。依据与出处见《17-数值公式与外部参考》。
- 6 个居民订单、商队装货与返航建材、成长任务、金币/经验/声望。
- 远方商会的大单：小镇 6 级起每 8 个游戏日多出一张周期大单，3–4 种**成品**、每种 8–13 件，按 3.2 倍货价结算（普通订单 2.8、商队 4.4，所以它是中间档），不能取消、交付后离场。货类取自 `TERMINAL_GOODS`——**从配方表推导**出「没有任何建筑把它当输入」的物资，因为第一版抽中羊毛与布料时实测**一次也交付不了**：中间品被下游工坊持续消耗，永远凑不够数。只收成品这条规则因此是结构性的，测试逐项断言大单里没有中间品。资格取决于**仓库里实际有多少**，不是「能造什么」：一个 60 人小镇每天穿掉 8 件衣物，而一座裁缝铺每天只缝 4.5 件，衣物永远停在个位数——所以「能造」不等于「能囤」，判据看现有库存（每种 ≥8 件、至少 3 种），请求量也取 min(8–13, 现有库存)，因此**一出现就能交付**。若始终凑不齐，商会约 3 个周期后自行撤回，订单板不会被一张填不上的单永久堵住。奖励只给金币与经验：大单若发声望会淹没《15》标定的 120 小时 167 点总量；建材则由商队供应，一条路线每小时 240 建材已超出全游戏 618 的总需求（2.6 小时即可覆盖）。实测 8 小时提供 41 次、交付 41 次（全部成交），约占三种收入的 46%，与商队同级。
- 集市可以进货：缺料不想等时，用金币买进面包、鲜鱼、工具、衣物、奶酪、蜂蜜与陈年佳酿，单价为卖出价的 18 倍，入口在仓库面板的「集市进货」。
- 集市**只卖成品，不卖原料与中间品**——这是硬约束，不是口味。第一版卖的是小麦、羊毛、布料这类原料，结果成了印钞机：买进来的货可以加工后再卖，而**工坊等级会把每段产出翻倍并沿链条累乘**，实测 1 级放大 16.67 倍（尚在 18 倍加价之内），**2 级 75 倍、3 级 266.67 倍**。第一版测试只算了 1 级所以放行。修法不是抬价（要覆盖 266 倍意味着一份小麦卖 500 金币以上，功能就没意义了），而是换货类：只卖「没有任何下游消耗」的货，放大恒等于 1，18 倍加价只需压过零售、商队与订单。测试现在**对 1/2/3 级分别重算**放大倍数，并断言集市卖的每种货都没有消费者。
- 商队在地图上真实出行：车身沿道路驶出集市、过桥、抵达对岸，去程载货、返程原路折回并调转车头，等你在集市交货时停成卸货姿态。路线用与居民相同的不切角四邻域寻路，集市搬迁或道路变化后会重算，因此车辙永远跟着实际道路走。
- 三条商队路线：溪谷集落（面包/木板/鲜鱼，最近）、山外集市（布料/衣物/工具，需裁缝研究）、下游河港（葡萄酒/奶酪/蜂蜜，需葡萄与酒研究）。货物、时长、回报各不相同，越远的路线每件货回报越高；路线各自从指定的桥出镇，因此地图上走的确实不是同一条路。选定的目的地写入存档，旅途中不可更改。
- 就近配套有真实收益：加工坊的原料由附近作坊供应时，每轮生产时间最多 −10%，并按**居民实际要走的格数**分级（贴邻居满额、6 格归零）。距离不再用直线量：实测密集小镇里 **24%** 的配对「直线近、实走远」（最坏一例直线 1.0 格、实走 49 格），隔着河或绕整排建筑都算远。实现上不能逐对寻路（一次 A* 25ms，逐对要 5.7 秒），改为**按资源做一次 BFS** 扫出全部距离，全量 3.1ms 后按布局缓存、命中约 0.02ms。这些数字都可用 `npm run scan:tuning` 复现。**地图上真的有搬运工**：每个生效配对派一位居民从产地走到作坊门口再折返，所以「绕远路」在屏幕上是看得见的。整排工坊紧贴、中间无路可走时退回直线距离（向上取整），因此排整齐的玩家不会因为这条规则吃亏；受损建筑仍然**挡路**，所以烧掉一栋房子不会反而缩短邻居的搬运、加快生产。只有真正的输入才算——裁缝铺摆在饲料坊旁无用，两座相同作坊互不供货，作坊也不给自己供货；渔屋、农田、采石场、矿场没有输入因而无关。加成是**省时间而非多产出**：本作按库存目标休工，所以更快的作坊在更短时间内做完同一批，把工人与土地更早腾出，而不是往仓库多塞货（测试断言两者批次完全相同）。建设计划「河谷匠人街」的配套判定与模拟层**调用同一个谓词**、共用同一半径，因此清单上打勾的和实际生效的永远是同一批建筑；`observe().production` 逐项报告 `localSupply`，详情面板写明是否已享受。开局 11 座符合条件的工坊里已有 6 座受益，所以这是第一天就能感觉到的布局回报，而不是要打通计划才解锁的东西。
- 信仰与康健（《05》L4 层）：新增**河畔小教堂**（无科技门槛，每级 14 户信仰与 8 点社区名额），诊所获得真正的医疗职能（`health` 10/级）。两项按「服务人数 ÷ 人口」折算，只减轻代价、不制造惩罚：信仰与康健一起把重税的**幸福惩罚减到最多八成**（留两成是因为重税的代价本身就是《05》第 4 节那个决策），康健再把**修缮的人工费减到最多三成**——但现买材料一分不减，否则会连带削弱《15》的应急安全阀。缺教堂、缺诊所的小镇幸福度与修缮费与从前逐位相同（有测试断言）。
- 美术：小教堂是单独生成的单帧图集（第 11 张，透明背景，可见像素 39.2%），由 `scripts/catalog-chapel.py` 裁剪加边后接入，原图与提示词一并入库。
- 住房、移民、饮水与环境需求、五档税率、节庆、四季农业变化。居民每天还会穿掉衣物、享用蜂蜜与奶酪等闲适点心（每 8 人 1 件衣物、每 10 人 1 份，按由廉到贵取用），备得越足幸福度最多多 8 点；**备不齐不扣幸福度**，四项基础需求的效果与从前完全一致，所以这是加工链深处的奖励而非新增门槛。
- 长期数值经过压力测试并修掉四处真实缺陷：**木材归零且产木建筑全损时无法修缮的死局**（现在短缺材料可用金币现买）、**受损越多被打击越狠的恶性反馈**（同时受损有上限、受损时灾害间隔拉长、人口过少不触发灾害）、**小城镇把人手派给不干活的作坊导致永远缺粮**（缺粮时按需要分配人手，吃饱时不重排）、以及**工人数被清零后再也回不来**（改为按编制重算，并新增 `staffing` 让玩家的显式编制不被覆盖）。详见《15-长时数值压力测试》。
- 小镇有自己的钟，长度与口粮、税收结算的「一天」共用同一个常量（90 秒），HUD 显示「第 N 天 HH:MM」与当前时段（夜里／清晨／白天／傍晚）。06:00 上工、20:00 收工；新开的小镇从 06:00 开始，所以打开游戏时街上已经在忙。约三分之二的居民有固定工作，白天沿真实道路通勤到作坊并以工作姿态劳作，傍晚回到各自的住处休息；余下的是孩子、老人与访客，任何时刻街上都有人走动。夜里作坊全关，不会有人还在工位上。
- 12 位邻居各有三段关系故事：搬进新家、作坊立起来、小镇长到一定规模，各开启一段。每段都问你怎么做，两个选项给的东西不同类——一样是立刻到手的货物与金币，一样是留在镇上的永久环境加成。没有会选错的选项，也不会错过：没答的故事原样等着。邻居说的话会点名附近**真正新建成**的那栋房子，而不是随机套话。
- 三种可收藏的街区风格：花巷、滨河步道、工坊广场。风格不看单件装饰，而是看**同一处**聚集了多少件相关摆设、其中有多少种——所以奖励的是连成一片的街角，而不是把地图铺满。每段风格各三级，成形后永久保留（拆掉也不收回），累计永久环境加成，并解锁一件可建造的纪念摆件（花车、野餐角、丰收堆，美术复用季节摆件图集）。摆件是纯装饰：不耗工人、不产出、不研究，建造面板会直接写明还差哪一步。
- 26 项成就：田园、小镇、产业、往来、生活五类。条件全部挂在真实递增的计数器上（收获量、订单、商队、修缮、科技、人口、园艺、土地、装饰种类、建设计划阶段等），达成即自动记录并奖励声望，不需要领取，也没有倒计时或错过惩罚。奖励只发声望不发金币——评审文档明确写过不要把一切都换算成更多金币，且声望在本作中本就代表认可（它解锁科技）。
- 12 位具名邻居：林莳、鲁班生、苏草、田伯、米洛、老渔、麦香、阿岳、闻书、安和、花间、陈酿。每位都有自己的立绘、住处与做工的地方，住处或工坊搬迁后指向随之更新；住处受损时会说明「暂时借住在别处」。名单随人口增长（每 2 位居民一位），全部由小镇实际建筑推导，没有写死在界面里。
- 温和的季节活动：每季一场自愿活动（春日花市、夏夜果摊、秋收宴、冬日灯火），只在当季可办，错过毫无损失。活动只取富余物资——建造木材与三日口粮受保护，不够时会明确告诉你还差多少。举办期间议事厅旁摆出对应摊位，幸福度提升持续一段时间后自然结束。
- 五种季节性灾害：火情、水患、旱情、雹灾、虫害。按季节轮替出现，各打各的目标——火情只烧民居、工坊与市政，水患只淹河道两岸 9 格内的工坊，旱情、雹灾与虫害只伤农田。消防站与瞭望塔的覆盖范围可预防火情，所以布局本身就是防线。受损建筑停产并显示对应灾害画面；修缮是有工期的活，先扣该灾害的材料、挂上脚手架，完工才恢复生产。关闭「自然挑战」即不再发生新灾害。
- 小动物：可领养橘猫与小黄狗，上限随人口增长（每 6 位居民一只，最多 6 只）。它们不是装饰——每只认领一位邻居，沿同一套寻路跟在后面：小猫走得慢、跟得远，小狗跑得快。物种与跟随对象写入存档。
- 1× / 2× / 4× 与暂停；30 秒自动保存、3 个手动存档（每个槽位显示里面存的是几位居民、几级、多久以前）、CRC32 导入导出、最多 8 小时离线结算。离线结算与在线**使用同一套心情模型**：税率、受损、衣物、闲适、信仰与康健都计入，再扣掉离开期间的饥饿——所以为撑住重税而建的教堂与诊所，在挂机的八小时里同样有效（原先只是「离开时的值减饥饿」，那些建筑在玩家最依赖它们的时段完全没有作用）。
- 本地规则副官与统一 `window.gameTools` 接口，含领养小动物、举办季节活动与查询小镇生活状态；成就、街区风格与邻居故事进度也可通过观察接口读取，邻居故事还能通过工具代为回应；调用仍经过模拟层成本与参数校验。

完整操作说明见 [docs/10-新版操作指南.md](docs/10-新版操作指南.md)。工坊详情中的「在岗居民」可增加或减少人手；新居民不会凭空出现在所有工坊。

## 架构

- `src/sim/`：纯数据规则、时间推进、离线结算与 Agent 工具；不依赖 Phaser 或 DOM。
- `src/sim/atlases.ts`：所有生成图集的唯一登记处。帧矩形直接来自 `public/assets/*-frames.json`，与素材册读的是同一份数据，因此精灵位置不会在源码里被重新声明一遍。
- `src/sim/disasters.ts`：灾害定义（目标范围、季节、修缮成本、动画帧）与打击判定；`src/render/DisasterLayer.ts` 按同一份定义绘制火情、水患与修缮脚手架，画面和规则不会各说一套。
- `src/render/TownScene.ts`：相机、建筑、地面、居民与视觉反馈；`CaravanCart`、`SeasonalProps`、`DisasterLayer` 分别绘制商队、季节摊位与灾害/修缮。
- `src/ui/`：游戏 HUD、操作面板与响应式样式。
- `src/save/storage.ts`：Dexie/IndexedDB、事务写入、校验与备份。
- `public/assets/`：本地游戏素材。离线预缓存只收游戏实际加载的文件：`world.png` 是旧版遗留、代码从不加载，已排除出预缓存（省 2.5 MB），但文件保留在仓库备用；`verify-offline.mjs` 会断言每一个被排除的文件都确实无人引用。`frames.json` 描述实际精灵区域，`prompts.json` 与 `industry-prompts.json` 保留生成提示词。`industry.png` 为 8 座扩展工坊；`valley-scenery.png` 为山峰、矿石丘陵与森林图集，提示词保留在 `valley-prompts.json`。`citizens.png` 是 6 类居民、前后视角与交替步态图集，对应 `citizens-prompts.json`。图片使用内建 ImageGen 生成，未复用旧项目素材。
- `tests/sim.test.ts`、`tests/industry.test.ts` 、`tests/terrain.test.ts` 与 `tests/roads-crowd.test.ts`：资源守恒、越界/负数、订单/商队防重复、仓储、工人、离线时间与坏档测试。

数据版本 2。存档迁移的策略是**补全，不是修复**：游戏后来新增的字段若在存档里不存在，就按它的空值补齐——旧版资源列表缺少新资源、旧版统计缺少新计数，都能照常载入；而存档真正写错的地方（负数、小数、未知建筑或资源、不存在的选项）依然一律拒绝，不会用默认值掩盖。原有库存、建筑、人口、任务与时间戳始终原样保留。

数据库使用全新的 `dream-town-v2`，不读取或覆盖旧实现的数据库。自动档读取失败会停止自动写入，直到成功读取或导入有效存档。

## 本版范围

另有三本收集册与 12 段邻居故事，见上文。本版覆盖基础经营闭环、四条加工产业链（冶炼、纺织、乳品、酿酒）、8 项声望科技、有工期的灾害与修缮、会出行的商队、季节活动、小动物与 12 位具名邻居。

**2026-09-22 又补进十一条**（规格出处与取舍见 [docs/19-规划与实现对齐差异.md](docs/19-规划与实现对齐差异.md) §2.7—§2.17 与「二·补」）：

- **田里长出四张脸**：九种作物各自从萌芽、幼苗、长成到成熟四张画面，地块大小全程不变。
- **能听见的小镇**：69 座建筑各有环境音，按离镜头的远近混音，最多同时 6 条。
- **商队不再只有一支**：集市等级与声望最多支持 4 支同时出发，各自选路线、各自往返。
- **强盗与防御**：强盗会砸房子、抢仓库；路口岗哨、青岚兵营、青岚城堡三级警戒半径 5/8/11 格；石砌城墙自动拼接。
- **甘蔗 → 糖 → 面包**：糖厂把甘蔗熬成砂糖，面包房配方改为面粉 + 砂糖。
- **啤酒花 → 啤酒 → 酒馆**：酿酒坊可在葡萄酒与啤酒之间切换，啤酒要送到晚风酒馆才会换成心情。
- **猪场 → 肉铺 → 香肠 → 酒馆**：香肠同样是酒馆的下酒菜。
- **药草园 → 诊所**：药草让诊所多照顾最多五成居民；没有药草时诊所和从前一模一样。
- **猎人屋**：皮毛外销、鲜肉入肉铺。竞品原作把这座建筑标成「猎区会灭绝还会引发瘟疫」的陷阱，这里刻意没有照搬。
- **瘟疫**：全城状态，扣心情并损口粮，诊所缩短疫情；**不会让居民消失**——人口仍只由既有的「持续不开心才走人」决定。
- **疫情、商队与城墙的画面证据**：收尾时用无头浏览器逐项复验，并因此抓到一个真 bug（商队精灵池从未存回，地图上其实一辆车都没有）。第二批十张素材（居民搬运与劳作、灾害与修缮、商队、邻居立绘、街区装饰、季节摆件、乳品与酿酒、住宅成长、宠物、机械分层）已全部接入运行，不再是待接素材。
