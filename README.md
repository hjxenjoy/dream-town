# 梦想小镇 · 河畔新生活

基于 `docs/01—09` 重新初始化的 Web 单机经营游戏。全屏等轴小镇、绘本风格建筑、可直接点击收获与建造的地图，支持桌面与手机操作。

## 运行

需要 Node.js 22.18+。

```sh
npm ci
npm run dev
```

开发地址默认 `http://localhost:5173`。

```sh
npm test       # 59 项模拟、科技、地图、道路与存档测试
npm run build # TypeScript 检查、生产包与 PWA 离线缓存
npm run preview
```

PWA 离线缓存需要先联网访问一次生产预览或部署版本，开发模式不注册缓存。全部游戏资源随构建输出，不依赖远程字体或外部图片。

## 已实现

- Phaser 4 等轴世界：20 种生成建筑精灵、绘制麦田、46 × 46 两岸河谷、山区森林、六类写实居民、步行动画、收获标记与飘字。
- 居民、农业、工业、矿业四个分区，1,817 格可建设陆地、贯穿河流与两座桥梁；分区导航、全景地图和小地图定位。
- 免费搬迁、按分区整理工坊与可保存的位置还原；兼容当前重建版存档。
- 土路 → 石子路 → 青石板路，两点成路、差价升级与移除；建筑和道路互斥，铺设前整段校验。
- 居民沿四邻域路线绕开建筑、跨桥过河、优先走路面，建筑变化后重新规划；暂停与游戏速度同步。居民会区分状态：去工坊路上是搬运姿势，在工坊里是劳作姿势，其余时候散步——搬运与劳作取自 48 帧的动作图集，按各自的角色与朝向切换。
- 一键收取所有可入库的成熟产物，合并反馈，满仓批次保留。泥土、碎石、草丛地表与延伸背景，缩放时约束镜头范围。
- 拖动、滚轮与双指缩放，建造预览、地块验证、建筑点选、升级、拆除确认与材料回收。
- 21 种装饰：树木、喷泉、凉亭、长椅、花拱门，以及临街花箱、蔷薇花架、串灯花门、木栈道、滨河栏杆、遮阳伞座、垂柳、浮动码头、木箱堆、橡木酒桶、旧铁砧、彩旗招牌。全部不需要工人，提供环境加成，可免费搬迁与拆除。
- 会转的机械部件：风车叶片随磨坊开工转动、锯木厂锯轮、鱼塘水轮，以及铁匠锤与钓竿的摆动、矿场矿车。部件挂在建筑上各自的实测轴心，只在工坊真正生产时动——库存充足或暂停时当场停住。
- 住宅逐阶外观：林间小屋与田园小院各有三级独立美术，升级时当场换帧，不再是放大同一张图。其余建筑仍以单帧加缩放表示等级。
- 小麦 → 面粉 → 面包、木材/木板、石料与渔业，工人分配、原料消耗、仓库硬容量及售卖。
- 工业链：矿石 + 木炭 → 金属锭 → 工具；纺织链：小麦 → 饲料 → 羊毛 → 布料 → 衣物。
- 乳品与酿酒两条新产业链：饲料 → 鲜奶 → 奶酪；蜂场自产蜂蜜；葡萄 → 葡萄酒 → 陈年佳酿。共 6 座新工坊与 6 种新物资，「葡萄与酒」科技解锁后三位一体的葡萄酒线。加工越深越值钱：奶酪贵过鲜奶、陈年佳酿贵过葡萄酒。
- 8 项声望科技，永久解锁工坊、缩短生产时间、增加仓容与减轻税收惩罚。物资图标可追溯生产来源。
- 6 个居民订单、商队装货与返航建材、成长任务、金币/经验/声望。
- 商队在地图上真实出行：车身沿道路驶出集市、过桥、抵达对岸，去程载货、返程原路折回并调转车头，等你在集市交货时停成卸货姿态。路线用与居民相同的不切角四邻域寻路，集市搬迁或道路变化后会重算，因此车辙永远跟着实际道路走。
- 三条商队路线：溪谷集落（面包/木板/鲜鱼，最近）、山外集市（布料/衣物/工具，需裁缝研究）、下游河港（葡萄酒/奶酪/蜂蜜，需葡萄与酒研究）。货物、时长、回报各不相同，越远的路线每件货回报越高；路线各自从指定的桥出镇，因此地图上走的确实不是同一条路。选定的目的地写入存档，旅途中不可更改。
- 住房、移民、饮水与环境需求、五档税率、节庆、四季农业变化。
- 26 项成就：田园、小镇、产业、往来、生活五类。条件全部挂在真实递增的计数器上（收获量、订单、商队、修缮、科技、人口、园艺、土地、装饰种类、建设计划阶段等），达成即自动记录并奖励声望，不需要领取，也没有倒计时或错过惩罚。奖励只发声望不发金币——评审文档明确写过不要把一切都换算成更多金币，且声望在本作中本就代表认可（它解锁科技）。
- 12 位具名邻居：林莳、鲁班生、苏草、田伯、米洛、老渔、麦香、阿岳、闻书、安和、花间、陈酿。每位都有自己的立绘、住处与做工的地方，住处或工坊搬迁后指向随之更新；住处受损时会说明「暂时借住在别处」。名单随人口增长（每 2 位居民一位），全部由小镇实际建筑推导，没有写死在界面里。
- 温和的季节活动：每季一场自愿活动（春日花市、夏夜果摊、秋收宴、冬日灯火），只在当季可办，错过毫无损失。活动只取富余物资——建造木材与三日口粮受保护，不够时会明确告诉你还差多少。举办期间议事厅旁摆出对应摊位，幸福度提升持续一段时间后自然结束。
- 五种季节性灾害：火情、水患、旱情、雹灾、虫害。按季节轮替出现，各打各的目标——火情只烧民居、工坊与市政，水患只淹河道两岸 9 格内的工坊，旱情、雹灾与虫害只伤农田。消防站与瞭望塔的覆盖范围可预防火情，所以布局本身就是防线。受损建筑停产并显示对应灾害画面；修缮是有工期的活，先扣该灾害的材料、挂上脚手架，完工才恢复生产。关闭「自然挑战」即不再发生新灾害。
- 小动物：可领养橘猫与小黄狗，上限随人口增长（每 6 位居民一只，最多 6 只）。它们不是装饰——每只认领一位邻居，沿同一套寻路跟在后面：小猫走得慢、跟得远，小狗跑得快。物种与跟随对象写入存档。
- 1× / 2× / 4× 与暂停；30 秒自动保存、3 个手动存档、CRC32 导入导出、最多 8 小时离线结算。
- 本地规则副官与统一 `window.gameTools` 接口，含领养小动物、举办季节活动与查询小镇生活状态；成就进度也可通过观察接口读取；调用仍经过模拟层成本与参数校验。

完整操作说明见 [docs/10-新版操作指南.md](docs/10-新版操作指南.md)。工坊详情中的「在岗居民」可增加或减少人手；新居民不会凭空出现在所有工坊。

## 架构

- `src/sim/`：纯数据规则、时间推进、离线结算与 Agent 工具；不依赖 Phaser 或 DOM。
- `src/sim/atlases.ts`：所有生成图集的唯一登记处。帧矩形直接来自 `public/assets/*-frames.json`，与素材册读的是同一份数据，因此精灵位置不会在源码里被重新声明一遍。
- `src/sim/disasters.ts`：灾害定义（目标范围、季节、修缮成本、动画帧）与打击判定；`src/render/DisasterLayer.ts` 按同一份定义绘制火情、水患与修缮脚手架，画面和规则不会各说一套。
- `src/render/TownScene.ts`：相机、建筑、地面、居民与视觉反馈；`CaravanCart`、`SeasonalProps`、`DisasterLayer` 分别绘制商队、季节摊位与灾害/修缮。
- `src/ui/`：游戏 HUD、操作面板与响应式样式。
- `src/save/storage.ts`：Dexie/IndexedDB、事务写入、校验与备份。
- `public/assets/`：本地游戏素材。离线预缓存只收游戏实际加载的文件：`world.png` 是旧版遗留、代码从不加载，已排除出预缓存（省 2.5 MB），但文件保留在仓库备用；`verify-offline.mjs` 会断言每一个被排除的文件都确实无人引用。`frames.json` 描述实际精灵区域，`prompts.json` 与 `industry-prompts.json` 保留生成提示词。`industry.png` 为 8 座扩展工坊；`valley-scenery.png` 为山峰、矿石丘陵与森林图集，提示词保留在 `valley-prompts.json`。`citizens.png` 是 6 类居民、前后视角与交替步态图集，对应 `citizens-prompts.json`。图片使用内建 ImageGen 生成，未复用旧项目素材。
- `tests/sim.test.ts`、`tests/industry.test.ts` 、`tests/terrain.test.ts` 与 `tests/roads-crowd.test.ts`：资源守恒、越界/负数、订单/商队防重复、仓储、工人、离线时间与坏档测试。

本次将新实现的数据版本从 1 升为 2。已有新版小镇的自动档、手动档和导出文件会在 CRC 校验后自动迁移，原库存、建筑、人口、任务和时间戳均保留；只补齐新资源、研究记录和成长任务。版本 2 的坏档不会被补默认值掩盖。

数据库使用全新的 `dream-town-v2`，不读取或覆盖旧实现的数据库。自动档读取失败会停止自动写入，直到成功读取或导入有效存档。

## 本版范围

本版覆盖基础经营闭环、四条加工产业链（冶炼、纺织、乳品、酿酒）、8 项声望科技、有工期的灾害与修缮、会出行的商队、季节活动、小动物与 12 位具名邻居。第二批十张素材（居民搬运与劳作、灾害与修缮、商队、邻居立绘、街区装饰、季节摆件、乳品与酿酒、住宅成长、宠物、机械分层）已全部接入运行，不再是待接素材。

仍是后续里程碑的内容：多种远行商队与商队路线选择、完整成就系统、完整职业通勤模拟（居民目前仍按目的地随机散步，不按时段上下班）、大模型 API/Ollama 接入，以及长时数值平衡（尚未做 5 小时实体游玩验证）。当前副官是实际运行的本地规则助手。原始设计文档保持原样。
