# 作物成长表现 · 2026-09-12

本轮补齐九种作物的中期生长画面，不新增照料动作、任务或经济消耗。

- 进度低于 22%：萌芽。苹果树和葡萄保留无果的树体与支架。
- 22% 到 72%：使用各自的绿色生长图；番茄、草莓和南瓜可见花朵。
- 72% 后：进入成熟前画面。只有模拟层 `ready` 为真才显示可收获。
- 休耕：回到空田；恢复种植后重新按进度显示。
- 田园面板同步显示“正在萌芽 / 枝叶渐丰 / 快成熟了”，保持自动续种与当前收成。

## 素材

使用内建 ImageGen，以现有 `public/assets/crops.png` 为风格参考生成新图，未替换成熟素材。

- 原图：`output/crop-growth-2026-09-12/crops-growing.png`
- 完整提示词：`output/crop-growth-2026-09-12/prompt.txt`
- 游戏图集：`public/assets/crops-growing.webp`
- 帧目录：`public/assets/crops-growing-frames.json`

实际尺寸 1254 × 1254，RGBA，九帧；约 50.2% 完全透明像素。按实际画面分区登记，九帧边界均无 alpha > 32 的像素，避免相邻作物串图。WebP 使用质量 90、alpha 100 转码。
