# 02 · 梦想小镇 (Township) 玩法拆解

## 1. 核心循环（经济本质）

玩家社区对 Township 经济的解构揭示了**两个正循环**，其唯一瓶颈源头是**矿石**：

```
循环 A（金钱线）：
  人口 → 解锁耕地 → 产出货物 → 直升机订单换金币/经验 → 升级/建房 → 人口

循环 B（建设线）：
  火车运货 → 换回建材(钉子/锤子/油漆)与挖矿工具 → 挖矿 → 矿石冶炼成金属锭
  → 金属锭升级火车(缩短往返时间) / 加速建筑 / 船运加成 → 火车效率提升 → 更多建材
```

```
                ┌──────────┐
   金币/经验 ←──│ 直升机订单 │←── 货物 ←── 耕地 ←── 人口
                └──────────┘                    ↑
                                                └── 房屋 ←── 建材 ←── 火车
                                                                      │
   金属锭 ──→ 升级火车(时间-50%封顶) / 船运加成 ──→ 火车/港口效率 ──────┘
       ↑
   矿石 ←── 矿井(挖矿工具来自火车)
```

**设计启示**：好的经营游戏需要一个"瓶颈资源"把多条循环拧在一起。Township 的瓶颈是矿石；它让玩家所有子系统都间接服务于采矿效率。

## 2. 种植与生产链

### 作物（部分）
小麦、玉米、胡萝卜、甘蔗、棉花、薰衣草、苹果（果树）等。作物是**一切产业链的源头**。

### 畜牧
喂作物产奶/蛋/羊毛：奶牛场（牛奶）、鸡舍（鸡蛋）、羊圈（羊毛）、蜂房（蜂蜜）等。

### 工厂加工（多级链）
| 层级 | 示例 |
| :--- | :--- |
| 一级加工 | 磨坊（小麦→面粉）、乳品厂（牛奶→奶酪/黄油）、糖厂（甘蔗→糖）、饲料厂（作物→饲料） |
| 二级加工 | 面包房（面粉+糖→面包）、纺织厂（羊毛→布料）、糕点厂 |
| 高级加工 | 冶炼厂（矿石×5→金属锭）、橡胶厂、造纸厂、珠宝店（矿石深加工） |

**攻略共识**：开局优先把糖/奶/面包/饲料四条食品加工链跑顺，再扩展畜牧→岛屿→橡胶等后续链条；工厂要**保持运转不空转**。

## 3. 订单系统（直升机）

- 城镇居民通过直升机订单板下订单，用货物换**金币 + 经验值**，是最直接的收入来源。
- 订单**无时间限制**，可能要求当前无法生产的物品；可取消订单，但下一单需等待约 30 分钟。
- 奖励与物品稀有度/数量正相关，形成"为订单而排产"的每日目标感。

## 4. 运输系统（三级解锁）

| 系统 | 解锁 | 机制 |
| :--- | :--- | :--- |
| **火车** | Lv.5 | ≥3 节车厢，装满发车；往返 2~5 小时，回程带回**建材与挖矿工具**。最多修复 3 条铁路；用金属锭升级可将时间最多压缩 -50%。中后期核心供给线 |
| **飞机** | Lv.17 | 修复机场后使用。15 小时内备好 3 组同类货物（每组 2~3 个）装机；每交 1 组得金币，满 3 组额外得绿钞与宝石。超时可强制发出但损失大部分奖励。班机间隔 5 小时 |
| **港口/船** | 随等级 | 最多 4 艘船（第 1 艘免费，之后 5,000 / 8,000 / 25,000 金币），每船最多 3 箱。驶往 4 个岛屿获取本地无法生产的特产：<br>· 水果岛：桃/西瓜/李子<br>· 橄榄岛：葡萄/橄榄/青柠<br>· 热带岛：香蕉/椰子/菠萝<br>· 渔人岛：鱼/虾/龙虾<br>每次航行可附加 1 个金属锭提升收获品质 |

## 5. 矿井（Lv.21）

- 四种矿石：铜、银、金、铂金；每 5 个矿石在冶炼厂炼成 1 个金属锭（冶炼厂单队列）。
- 三种挖矿工具：**镐**（敲 1 格）、**炸药**（炸一整行）、**TNT**（炸周围一圈）——工具与矿石不占仓库容量。
- 矿井中可挖出宝箱、金币、古董藏品等随机奖励。

## 6. 仓库（Barn）—— 核心压力机制

- 所有物品经仓库中转，**容量有硬上限**；仓库满则无法完成订单。
- 升级仓库消耗钉子/锤子/油漆（来自火车），且每次升级所需数量递增。
- 仓库还堆放社区建筑建材与扩地工具（铲子/斧头/锯片），多重挤占。
- 可低价抛售物品腾空间（惩罚性出口）。
- **设计作用**：用容量限制制造"取舍"决策，是 Township 最主要的进度阀门。

## 7. 人口与社区建筑

- **人口决定耕地数量**：人口越多可建耕地越多（循环 A 的起点）。
- 人口上限由**社区建筑**（学校、医院、剧院等）提升，社区建筑的建材只能来自火车/市场。
- 扩地：前期只需金币，后期需要铲子/斧头/锯片（同样只能火车获取）。

## 8. 动物园（Lv.24）

- 用城镇产出的物资建设与升级围栏、引进动物家庭。
- 解锁新动物可附带解锁动物园配套商铺（咖啡馆/纪念品店/快餐店），形成独立于主镇的第二条养成线，并参与赛舟会任务。

## 9. 社交与活动（本项目移除/单机化）

- **合作社 (Co-op)**：Lv.19 解锁，成员间互相援助装填订单。
- **赛舟会 (Regatta)**：每周团队竞赛，成员限时完成指定任务积分，胜出队伍获奖。
- **每日奖励 (Daily Bonus)**：连续登录递增奖励。
- **限时活动**：7~10 天周期的三消/烹饪小游戏（如 Italian Week、Color Splash），排行榜+进度奖励，反哺主游戏材料。
- **赛季通行证**：Professor's Experiments（2019.11 上线，当季带来 22% 收入增长）。

> 单机化替代方案：合作社→NPC 商队订单；赛舟会→每周挑战任务；通行证→成就树。

## 10. 货币体系

| 货币 | 获取 | 用途 |
| :--- | :--- | :--- |
| 金币 | 订单/卖货物 | 建造、扩地、买船 |
| 绿钞 (Township Cash) | 飞机满舱/成就/内购 | 加速、买商人格子、应急补货 |
| 宝石 | 飞机/矿井/活动 | 兑换稀有物品、实验室增益 |
