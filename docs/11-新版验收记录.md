# 新版验收记录

验证环境：Node.js 22、Phaser 4.2.1、Vite 6、Codex 内置浏览器，桌面 1280×720 与手机竖屏 390×844。

## 通过

- 25 项纯模拟测试：建造成本与地块、生产扣料、仓库容量、订单与商队防重复、税率、任务、规则副官、工人分配、离线时间锚点、损坏存档与受损住宅拆除。
- TypeScript 检查及生产构建。
- 桌面端真实操作：交付订单、商队装货与返回标记、空地建民居、地图点选收获、任务进度增长。
- 手机端：镜头居中、完整底部操作栏、竖屏订单面板、订单交付、设置与手动保存。
- IndexedDB：手动保存成功；刷新恢复原镇人口、金币、库存；离开后显示离线收益报告。
- 离线启动：生产缓存就绪后，终止本地预览服务，再刷新页面；游戏世界、HUD、建筑精灵和建造目录均完整显示。
- 浏览器运行日志检查未见 JavaScript 错误。

## 已修复的重点问题

- 建造成功后清除放置提示，避免继续显示建造模式。
- 屏幕尺寸变化后重新居中，手机提供回到小镇中心入口。
- 面板保留焦点时继续更新倒计时与数据；拆除确认不会被自动刷新关闭。
- 新工坊不能凭空获得超出人口的工人；支持在界面调配工人。
- 离线结算不能重复领取同一时间段，系统时间回退不产生收益。
- 精灵目录中的 SVG 显式裁切，避免相邻素材出现在留白区域。
- Workbox 缓存清单移除重复与冲突项；固定名称素材带版本校验。构建自动检查全部必需文件和清单唯一性。

## 验证边界

手机竖屏使用浏览器视口验证，未覆盖所有实体设备。生产缓存的断服刷新已实测；添加主屏幕安装仍取决于浏览器支持。长期经营平衡、复杂灾害与扩展产业请参见 README 的本版范围。
