# 06 · 订单、运输与离线收益机制（本项目）

## 1. 订单系统（直升机订单的单机化）

学 Township：订单是"最直接的收入来源"和每日目标感的来源。

- **订单板**：NPC 居民/邻镇商人发布，用货物换金币+经验；同时挂 6~10 单。
- 订单无时限，可取消（冷却 10 分钟游戏时间）。
- 难度自适应：只生成"玩家已解锁产能"的货物订单，稀有货物单价更高。
- 特殊大单：周期性"商队大订单"（多品类组合），奖励建材包（学飞机满 3 组给绿钞的阶梯奖励）。

## 2. 运输系统（商队，离线友好改造）

Township 的火车/飞机/船本质是"**定时器 + 资源转换器**"。离线单机版统一为**商队**：

| 商队类型 | 解锁 | 机制 |
| :--- | :--- | :--- |
| 陆路商队 | 前期 | 装上货物发出 → 游戏时间 2~4 小时后返回，带回金币溢价 + 概率带回建材包/扩地工具 |
| 河道船队 | 中期 | 往返更久（6~10 小时），可前往 3 个"特产聚落"换取本地无法生产的稀缺品（学港口四岛） |
| 远行商队 | 后期 | 过夜级（离线结算主力），高回报高风险（遇强盗概率，需护卫） |

- 商队数量/舱位通过声望与建筑升级扩展（学火车最多 3 辆、船最多 4 艘的硬上限设计）。
- 可消耗金属锭升级商队，缩短往返时间（上限 -50%，学火车升级）。

## 3. 离线收益结算（离线游戏的关键设计）

不使用真实时间强制等待；游戏内时间在离线期间按公式**一次性结算**，而非逐 tick 模拟：

```
离线时长 t = min(现实离线时长, 8 小时封顶)

结算规则:
  1. 生产建筑: 产出 = t / 生产周期 × 效率，受限于
     - 原料库存(链式消耗，自上游向下游结算)
     - 仓库剩余容量(满了停产)
  2. 居民消耗: 食物按人头扣减; 库存耗尽则离线期间幸福度下降, 不死亡不搬离(惩罚封顶)
  3. 税收: 按离线期间平均幸福度对应税率结算金币
  4. 商队: 在途商队若预计返回时间 < t, 直接结算到货
  5. 灾害: 离线期间不触发灾害(保护性设计), 但上线后 5 分钟内提高触发率补偿
```

- 上线弹出**离线收益报告面板**（收成了什么、消耗了什么、税收多少、商队到货）——离线游戏最重要的正反馈时刻。
- 8 小时封顶防止"睡一觉暴富"，引导玩家每日多次回访。

## 4. 仓库压力机制（保留 Township 的 Barn 设计）

- 统一仓库容量上限，所有物资经此中转；
- 升级消耗建材包且数量递增；
- 满仓时生产停摆、订单无法交付——制造持续的"卖什么/留什么/升仓库"取舍；
- 允许低价抛售腾空间（惩罚性出口阀）。

## 5. 季节系统

- 游戏内四季循环（每季 = 固定游戏日数）；
- 冬季农田休耕减产，渔业/林业全年稳定（保留 Townsmen "鱼木开局"的策略深度）；
- 季节影响视觉（雪/落叶）与订单结构（冬季食品订单溢价）。
