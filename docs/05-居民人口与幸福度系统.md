# 05 · 居民、人口与幸福度系统（本项目）

## 2.8 补充

园艺每升一级，自然增加 2 位社区人口名额（园艺最高 30 级，共可增加 58 位）。与学校、诊所、剧院及已有称号名额叠加，入住仍受健康住宅床位、幸福度与口粮限制。无需任务交付或领取。

## 1. 人口模型

```
建房/升级民居 → 空床位 → 移民入住(条件: 幸福度 ≥ 阈值 且 粮食库存 ≥ 3 日)
居民 = 生产者(上班) + 消费者(需求) + 纳税人(人头税)
```

- **人口决定用地规模**（学 Township）：人口越多，可开垦的农田/区域越多。
- 人口上限由**社区建筑**（学校/诊所/剧院）提升——建材可来自商队运输，或采矿研究后由窑火建材坊本地制造（6 石料 + 1 木炭 → 1 建材）。社区名额与住宅床位共同限制可入住人口。
- 移民流入速率与幸福指数正相关；幸福度崩坏则居民搬离（负增长）。

## 2. 需求分层（马斯洛式递进）

| 层级 | 需求 | 满足建筑/物资 | 不满足后果 |
| :--- | :--- | :--- | :--- |
| L1 生存 | 食物、饮水 | 鱼/面包/肉；水井 | 幸福度急跌，停止纳税，搬离 |
| L2 温饱 | 衣物、燃料(冬) | 裁缝铺衣物；木板/木炭 | 幸福度缓降，效率下降 |
| L3 小康 | 娱乐、酒馆 | 酒馆(啤酒/香肠)、娱乐场 | 无法升高档税率 |
| L4 富足 | 信仰、医疗 | 教堂、医馆 | 瘟疫易爆发；顶层税率锁死 |

## 3. 幸福度计算模型

```
幸福指数(0~100) = Σ(需求满足率 × 权重) − 税率惩罚 − 灾害惩罚 + 节庆加成

权重(初版): 食物 30 / 饮水 15 / 衣物 15 / 娱乐 15 / 信仰 10 / 医疗 10 / 环境 5
税率惩罚: 税率每 +1 档，幸福 −6
灾害惩罚: 火灾受损 −10(逐日恢复) / 瘟疫期间 −20 / 被抢 −8
```

## 4. 税收档位（核心决策点）

| 档位 | 税率 | 效果 |
| :--- | :--- | :--- |
| 免税 | 0% | 幸福 +5/日，移民加速 |
| 低 | 5% | 无惩罚 |
| 中 | 10% | 幸福 −6 |
| 高 | 15% | 幸福 −12，需 L3 需求满足才可长期维持 |
| 重 | 20% | 幸福 −20，仅短期应急（灾后重建募资） |

**设计张力**：玩家每季度做一次"提税增收 vs 保幸福保人口"的权衡——这是 Townsmen 最经典的经营决策。

## 5. 居民个体表现（氛围层，低成本高回报）

Townsmen 被社区盛赞的"精度用在刀刃上"设计，本项目以 2D 精灵低成本复刻：

- 居民有住所→工作地两点通勤动画（A* 寻路）；
- 建筑专属音效：市场喧闹、铁匠铺敲打、磨坊吱呀、酒馆歌声；
- 状态外化：幸福时闲聊/节庆跳舞，不满时聚集抱怨，重税时罢工（生产停摆）；
- 灾害时强盗进村与守卫决斗的小剧场。

## 6. 声望与科技

- 完成任务链（NPC 委托/里程碑）获得**声望**；
- 声望解锁：新建筑蓝图、科技升级（生产 -10% 时间、仓库 +20%、税率惩罚减半等）、剧情章节；
- 单机替代 Township 赛季通行证的长期目标系统：**成就树**（人口 100 / 全建筑解锁 / 无伤抗过瘟疫……）。
