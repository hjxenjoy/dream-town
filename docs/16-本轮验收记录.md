## 三、本轮修掉的问题

按「玩家能不能感知」排序，前三条都会造成真实损失。

| # | 问题 | 证据 |
| --- | --- | --- |
| 1 | **旧存档无法读取**：v2 存档缺新增资源键时被判定损坏，小镇无法载入 | 真实存档在浏览器里触发「自动存档已保护」；取出 IndexedDB 内容在 Node 中定位到缺 6 个资源键；修复后同一存档正常载入 |
| 2 | **不可恢复的死局**：木材为 0 且产木建筑全损时，游戏内不存在任何取得木材的动作，而离线报告说明「玩家离开」是被支持的场景 | 逐项实测七种取木手段全部产出 0；修复后废墟可在 10 小时内恢复（人口 4→24、幸福 15→85、受损归零） |
| 3 | **灾害的恶性反馈**：修缮需求随受损数上升、收入随停产数下降，落后的小镇永远追不上 | 修复前疏忽 8 小时后 16/19 受损且 5 小时照看仍剩 13 座；修复后同情境只剩 1 座 |
| 4 | **小城镇把人手派给不干活的作坊**，导致永远缺粮、人口不涨 | 4 人小镇原本 0 人渔场；修复后渔场优先获得人手，且吃饱的小镇不重排 |
| 5 | **工人数被清零后无法恢复**（`workers ?? max` 对 0 失效） | 修复后空闲人手会回填；新增 `staffing` 让玩家显式编制不被覆盖 |
| 6 | **商队路线没真正走指定桥**：A* 就近选了另一座桥再沿对岸绕行 | 修复前 valley/hilltown 都经过 15 号桥；修复后各走各桥（见上表） |
| 7 | **被拒绝的出发会改动状态**（先写清单再校验货物） | 单测锁定：拒绝时状态逐字节不变 |
| 8 | **12 个第三阶段全是「持久 vs 持久」**，两个选项只在数值与措辞上不同 | 改为一边实收货物与金币、一边留永久加成 |
| 9 | **第一阶段索要蜂蜜、矿石、葡萄**等开局不可能有的物资 | 改为只索要开局可生产的物资，并有测试守住 |

## 四、新增内容一览

| 系统 | 内容 | 存档字段 |
| --- | --- | --- |
| 成就 | 26 项分五类，条件挂在真实单调计数器上，自动达成、奖励声望 | `achievements`（可选） |
| 商队路线 | 3 个目的地，各有货物、时长、回报与指定的桥；两项需研究解锁 | `caravan.destination`（可选，默认 valley） |
| 街区风格 | 3 种风格各 3 段，按「同一处聚集的件数与种类」判定，永久保留并解锁 3 件纪念摆件 | `collections`（可选） |
| 邻居故事 | 12 位邻居各 3 段，由真实建设开启，每段两种做法（即时收获 / 永久加成） | `stories`（可选） |
| 小镇时钟 | 90 秒一天（与经济日共用同一常量），四时段；约 2/3 居民按钟点通勤；新镇从 06:00 开局 | 无需新增（用 `gameTime`） |
| 劳动力 | 新增 `staffing` 记录玩家显式编制 | `staffing`（可选） |

所有新增字段均为可选并有默认值，因此旧存档继续可读；未知值、越界值、非法选项一律拒绝。
