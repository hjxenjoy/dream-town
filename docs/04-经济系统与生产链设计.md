# 04 · 经济系统与生产链设计（本项目）

融合 Township 的订单驱动生产链与 Townsmen 的居民消耗经济。所有数值为初版框架，供后续平衡迭代。

## 1. 资源分类

| 类别 | 资源 | 来源 |
| :--- | :--- | :--- |
| 基础采集 | 原木、石料、鱼、矿石(铜/铁/金) | 伐木场、采石场、渔屋、矿场 |
| 农作物 | 小麦、玉米、胡萝卜、甘蔗、葡萄 | 农田（受季节影响） |
| 畜牧 | 牛奶、鸡蛋、羊毛、肉 | 牧场（消耗饲料） |
| 一级加工 | 木板、面粉、糖、布料、木炭、金属锭 | 锯木厂、磨坊、糖厂、纺织厂、炭窑、冶炼厂 |
| 二级加工 | 面包、奶酪、衣物、啤酒、工具、香肠 | 面包房、乳品厂、裁缝铺、酿酒厂、铁匠铺、肉铺 |
| 特殊 | 建材包(钉/锤/漆)、扩地工具(铲/斧/锯) | **仅由商队运输带回**（瓶颈资源） |
| 货币 | 金币（税收/订单/售卖） | — |

## 2. 生产链图谱

```
                        ┌─→ 磨坊 ─→ 面粉 ─→ 面包房 ─→ 面包 ──→ 居民消费/订单
  农田 ─→ 小麦 ─────────┤
                        └─→ 饲料厂 ─→ 饲料 ─→ 牧场 ─→ 牛奶 ─→ 乳品厂 ─→ 奶酪
  农田 ─→ 甘蔗 ─→ 糖厂 ─→ 糖 ─→ 面包房(配方原料)               └→ 羊毛 ─→ 纺织厂 ─→ 布料 ─→ 裁缝铺 ─→ 衣物
  农田 ─→ 葡萄 ─→ 酿酒厂 ─→ 葡萄酒/啤酒 ─→ 酒馆(居民娱乐消费)
  伐木场 ─→ 原木 ─┬─→ 锯木厂 ─→ 木板 ─→ 建造/升级
                  └─→ 炭窑 ─→ 木炭 ─→ 冶炼厂/铁匠铺(燃料)
  矿场 ─→ 矿石 ─→ 冶炼厂 ─→ 金属锭 ─→ 铁匠铺 ─→ 工具/武器盔甲 ─→ 士兵装备/市场高价品
  渔屋 ─→ 鱼 ──→ 居民食物(直接) / 肉铺 ─→ 香肠(酒馆)
```

## 3. 瓶颈资源设计（学 Township 的"矿石枢纽"）

- **金属锭**：升级运输效率、建造高级建筑的必需 → 把矿场-冶炼-铁匠链拧进所有循环。
- **建材包**：只从商队运输获得，无法本地生产 → 驱动玩家持续跑订单/运输。
- **仓库容量**：所有物资经仓库中转，升级仓库消耗建材包且递增 → 制造持续的取舍压力。

## 4. 数值框架（初版）

| 环节 | 产出周期(游戏内) | 投入 | 产出 | 参考售价(金) |
| :--- | :--- | :--- | :--- | :--- |
| 小麦(农田) | 1 季 | 人力 | 4 单位 | 2/单位 |
| 鱼(渔屋) | 2 分钟 | — | 2 单位 | 1/单位 |
| 原木(伐木场) | 3 分钟 | — | 2 单位 | 2/单位 |
| 面粉(磨坊) | 2 分钟 | 2 小麦 | 2 面粉 | 5/单位 |
| 面包(面包房) | 3 分钟 | 2 面粉 + 1 木(燃料) | 3 面包 | 8/单位 |
| 布料→衣物 | 5 分钟 | 2 羊毛 → 1 布料 → 1 衣物 | 1 衣物 | 25/件 |
| 金属锭(冶炼厂) | 10 分钟 | 5 矿石 + 2 木炭 | 1 金属锭 | 60/锭 |
| 工具(铁匠铺) | 8 分钟 | 1 金属锭 + 2 木板 | 2 工具 | 80/对 |

**平衡原则**：
1. 每级加工附加值约 ×2~3，鼓励深加工而非卖原料；
2. 居民食物消耗 ≈ 1 单位/人/游戏日，渔屋开局 3 座可养约 15 人；
3. 税率产生的金币增速应始终低于"卖货"上限，防止纯税收挂机碾压生产玩法。

## 5. 多流派验证

设计上保证三条路线都可通关（源自 Townsmen 农业流/工业流的社区验证）：
- **农业流**：渔+面包+衣物，零矿业，靠人头税与食品贸易；
- **工业流**：矿业+冶炼+工具出口，高资本投入高回报；
- **贸易流**：市场倒卖 + 订单优先，靠价格波动与商队差价。

## 6. 2026-09 经济平衡修订（当前实现）

以上表格为最初设计框架；当前游戏以 `src/sim/data.ts` 的生产周期和配方为准。本轮针对“满仓原料、木材和口粮短缺”调整如下：

- **按需生产**：按总仓储与已建产业分配补货目标，目标总量约占容量的 82%，其余用于整批收获、商队回程和周转。木材、木板、石料和口粮获得较高份额，中间材料保留较小缓冲。增加同类农田提高补货速度，不会放大它的仓储份额。达到目标自动休工，消耗后自动复产；待收批次也计入目标，避免大量农田同时挤占仓库。
- **木工坊**：一级均衡配方由 `3 木材 + 1 木板` 改为 `6 木材 + 2 木板`；木材优先为 `10 木材`，木板优先为 `2 木材 + 4 木板`。保留原有升级产量与速度加成。均衡模式在木板充足时改采木材；只采集库存短缺的品类，已完成批次不因切换而改变。
- **燃料**：炭窑每轮耗木从 3 降为 2，仍产出 2 木炭。炭窑保留总容量 8% 的建造与取暖木材，最低 12、最高 60；面包房不受这条保留线限制，避免燃料保护阻断口粮。
- **加工仓位**：按产出减投入的净增量核算。满仓仍能加工等体积或压缩体积的配方；增长型配方同时预留已完成待收批次的仓位。
- **富余出售**：仓库分成建造采集、居民口粮、农产加工、成品贸易四组，展示目标和富余数。可整批或按品类出售富余，保留正常目标与当前全部订单所需量的较大值，建材包不纳入富余出售；原有手动卖 5 份入口保留。
- **市长助手**：仓储超过 88% 时优先出售真正富余的物资，然后按短缺程度批量收取。收取不再阻断后续订单决策；订单保留三日口粮和建造木材，取消按资源枚举顺序卖木材的逻辑。
- **离线**：最多八小时，每不超过五秒按生产链结算，穿插每日口粮与冬季取暖消耗，应用相同补货与木材保留规则。维持离线不执行副官决策、不触发灾害、不改变人口的边界；报告逐项累计产出、消耗与税收。

更新直接兼容现有二版存档，不清空库存、不改建筑等级、不增加或回收仓储容量。木工坊新增的可选生产方向经存档验证并持久保存，旧工坊默认均衡补货。既有积压由玩家在仓库选择出售，或由已开启的市长助手按上述规则处理。

## 2.6 · 扩城生产补充

新增专职伐木屋、锯木厂、养鱼场、建材坊，沿用已有资源类型与仓储补货目标，不新增挤占仓库的资源。锯木厂和炭窑都保留建造用木材，厨房仍可为口粮使用木材。建材坊把石料和木炭加工为升级建材，补充商队渠道；按来源到成品的顺序参与在线与离线生产。具体配方见新版游玩指南。
