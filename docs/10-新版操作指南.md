# 10 · 青岚小镇：新版操作指南

## 启动游戏

在项目根目录运行：

```sh
npm install
npm run dev
```

打开终端显示的本地地址。项目的生产构建命令为 `npm run build`；`npm run preview` 用于预览构建结果。

## 在小镇里移动

| 操作 | 鼠标 / 触控板 | 触屏 |
| --- | --- | --- |
| 平移地图 | 按住地图拖动 | 单指拖动 |
| 缩放地图 | 滚轮缩放 | 双指捏合 |
| 选择建筑 | 点击建筑或建筑上方标记 | 轻点建筑或标记 |
| 建造 | 选择建筑后，点击空地 | 选择建筑后，轻点空地 |

绿色的建造预览表示该地块可以放置，红色表示地块不可用或已被占用。建筑需要的金币、材料，以及麦田数量限制，仍以建造操作的检查结果为准。进入建造模式后会出现地格，拖动地图仍可调整视野。

建筑上方的勾号表示产出已就绪；感叹号表示建筑受损。生产建筑下方的小进度条显示这一轮生产的进度。

桌面端也可以使用快捷键：

| 按键 | 操作 |
| --- | --- |
| `Space` | 暂停 / 继续游戏 |
| `B` | 打开 / 关闭建造目录 |
| `I` | 打开 / 关闭仓库 |
| `O` | 打开 / 关闭订单 |
| `T` | 打开 / 关闭科技蓝图 |
| `Esc` | 返回上一层：关闭离线报告、取消拆除确认、取消建造或关闭面板 |
| `H` | 回到小镇中心 |

右下角可选择 1×、2×、4× 游戏速度。生产、居民消耗、订单等待和商队倒计时都使用游戏时间；暂停后这些进度停止。触屏上的管理入口位于底部，设置、音效、全屏和指南位于左侧。

## 第一段经营旅程

1. 收取成熟的麦田、木工坊与渔屋产出，完成「第一份丰收」目标。
2. 用已有库存交付居民订单，赚取金币和经验。备货不足的订单可以暂留；取消订单后，要等待 1 分钟游戏时间才能换到下一笔委托。
3. 留出面包、木板和鲜鱼，组织一次商队。基础旅程为 2 分钟游戏时间，返回后领取金币与建材包。
4. 用建材升级仓库或生产建筑；仓库每次扩建增加 80 格容量。建筑最高可升至 3 级。
5. 建造新住房、维持粮食与饮水供应，让新居民入住。保持幸福度有助于小镇继续发展。

第一条加工链是「小麦 → 面粉 → 面包」。木工坊同时提供木材与木板；鲜鱼可直接供居民食用。加工建筑需要原料，产出就绪后需要收取，才能继续下一轮生产。仓位不足时，可以优先交订单、出售一部分库存或扩建仓库。

建筑详情会显示本级的实际配方、产量和每轮时间。遇到原料不足、仓位不足、缺少工人或建筑受损时，状态栏会说明原因。暂停一座建筑只暂停它的生产，不会暂停整个小镇。

升级前可以看到所需金币、木材、石料与建材包，以及仓库中已有的数量。资源不足或建筑受损时，升级按钮不可用；修复需要 80 金币、3 木材与 2 石料。仓库页面也会显示扩建的完整费用。

拆除前会显示回收金额和材料、减少的床位或仓储容量。未收取的产物会随建筑丢失，拆除无法撤销；选择「再想想」或按 `Esc` 可以回到建筑详情。居民缺少替代住房，或拆除后的仓库无法容纳库存时，需要先解决相应问题。

订单中的数字按「已有 / 所需」显示，缺少的货物会标出。商队需要一座未受损的集市；货物备齐才能出发，升级集市可缩短旅程。商队返回后若仓位不足，先腾出放置建材包的空间，再领取奖励。

离线收益最多结算 8 小时，生产会受到原料、可用工人和仓库容量限制。离线期间仍会消耗食物、衣物与闲适点心，并结算税收；粮食不足会降低幸福度，但离线期间居民不会死亡或搬离，也不会生成新灾害。到期商队会进入已返回状态，奖励仍需在游戏里领取。

## 把作坊摆在原料旁边

加工坊的原料如果由**附近的作坊**供应，每轮生产时间就会缩短——近一点，省得多一点。这条规则从第一天起就有用：开局小镇的磨坊与牧场已经在享受它。

**距离按居民实际要走几格算，不是直线。** 隔着一条河，或者要绕着整排房子走，仓库里看着近，实际很远——这种情况下没有加成。你可以点一下作坊上方的搬运工，跟着看他们把货挑过去。

| 搬运距离 | 生产时间 |
| --- | --- |
| 紧挨着（走 1 格） | −10% |
| 走 3 格 | 约 −6% |
| 走 6 格 | 没有加成 |

几点值得知道：

- 只有**真的用得上**的邻居才算。裁缝铺摆到饲料坊旁边没有用，因为裁缝铺不吃饲料。
- 两座一样的作坊互相不算，作坊也不会给自己供货。
- 渔屋、农田、采石场、矿场不参与，因为它们不消耗原料——没有东西需要搬。
- **加成是省时间，不是多产出。** 本作按库存目标休工，所以更快的作坊不会往仓库里多塞货，它只是在更短的时间里做完同一批，把工人和土地更早腾出来。
- 把工坊排成一整片、中间不留空地的做法**不会因此吃亏**：那样虽然没有路可走，游戏会退回到按直线距离判断，等于维持原来的结果。

点选作坊即可看到它现在的搬运距离和节省比例；搬迁免费，所以试错没有代价。

「成长 → 建设收藏 → 河谷匠人街」的配套判定用的是同一个标准、同一个半径，也就是说这条路线要求你做的事，本身就会让作坊变快。

## 保存、导出与恢复

新版存档保存在浏览器的 IndexedDB 数据库 `dream-town-v2` 中，包含一个自动存档与三个手动槽位。不同浏览器、不同浏览器资料，以及不同网站地址之间的本地存档互相独立。

游戏每 30 秒自动保存。要保留当前小镇的一个阶段，可在「设置」中选择手动槽位保存。读取槽位或导入文件会切换当前进度；切换前可先保存到另一个槽位或导出备份。

导出功能会下载一个带时间戳的 `.json` 文件。文件包含游戏纯数据、格式版本与 CRC32 完整性校验。导入时会先检查文件格式、校验码和小镇数据；损坏的文件或不兼容的版本会显示错误，不会在校验阶段修改任何本地存档。

写入存档时先在同一事务内创建临时记录，读回验证后再替换目标槽位。任何步骤失败都会撤回整个事务，保留之前的存档。保存会更新副本的时间戳，不会改动正在运行的小镇对象。

清除网站数据或删除浏览器资料会同时清除本地存档。要在另一台设备继续，先导出 JSON，再在目标设备导入。

## 按自己的节奏经营

「设置」中的小镇副官是本地运行的规则助手，会按库存和需求收获、交付订单、安排商队、处理部分经营事务。它的操作仍受货物、金币、仓储和建筑条件约束。可随时让它休息，并在「工作手记」中查看近期操作。

自然挑战和音效都可以在设置中开关。自然挑战关闭时不会发生新灾害；已经受损的建筑仍需要修复。副官与自然挑战设置会随存档保存。

开启自然挑战后，灾害按季节轮替出现，各自只打特定的目标：火情会烧到民居、工坊与市政（消防站和瞭望塔的覆盖范围可以预防）；水患只淹河道两岸的工坊；旱情、雹灾与虫害只伤农田。受损的建筑会暂停生产，地图上显示对应的灾害画面与红色警告；点开建筑选择「安排修缮」，先支付这场灾害需要的金币与材料，工匠搭起脚手架，工期结束后自动恢复生产。修缮期间建筑仍然停产，但不会重复扣费。灾害不会摧毁建筑，也不会让居民离开。

河滩低地容易被水淹，把工坊搬离河道就是最省钱的防灾方式。

## 商队会真的上路

安排商队出发后，装好货的马车会从集市驶出，沿着你铺好的路走，过桥到对岸，再原路折回。返程车头会调转，回到集市停下等你交货——此时车上摆着要交给你的建材。

路线跟着实际道路走：把集市搬到别处、或者改动路面，马车下次出发就会走新路。所以铺一条顺路的桥边道路，商队看起来也更像样。

## 远方商会的大单

小镇升到 6 级以后，订单板上会**每隔约 8 个游戏日**多出一张「远方商会的大单」——暖黄色的卡片，标题旁边挂着「大单」标签。

它和普通订单有几处不同：

| | 普通订单 | 远方商会的大单 |
| --- | --- | --- |
| 内容 | 1–2 种物资，几件 | 3–4 种**成品**，每种 8–13 件 |
| 单价 | 约 2.8 倍货价 | 约 3.2 倍货价 |
| 换一份 | 可以，等 1 分钟 | **不可以**，只能备齐交付 |
| 交付后 | 原地换成新的一笔 | 整张离场，等下一次周期 |

它只收**成品**：面包、鲜鱼、工具、衣物、奶酪、蜂蜜、陈年佳酿。不收羊毛、布料、面粉这类中间品——那些是织坊、裁缝铺、面包房正在用的东西，仓库里本来就不会堆起来。所以看到大单要什么，就知道该去把哪条链的末端开足。

**什么算够格**：小镇要**同时囤着至少 3 种成品、每种 8 件以上**，大单才会来。判据看的是仓库里**实际有什么**，不是「能造什么」——这两件事不一样：居民每天会穿掉衣物、吃掉奶酪和蜂蜜，所以一个只有一座裁缝铺的小镇，衣物永远停在个位数，够不着门槛。

最容易凑齐的一条是**工具**：居民不穿也不用工具，只要建起矿场 → 炭窑 → 冶炼坊 → 铁匠铺，工具就会稳定积累。面包和鲜鱼同理，通常是最先满足的两项。衣物、奶酪、蜂蜜要靠更完整的产业链才囤得住。

大单来的时候会在镇上留一条消息。**如果一直凑不齐，商会会自己撤回**（约 3 个周期之后），订单板不会因此被堵住。

大单只给金币和经验，不给声望也不给建材——声望要留给科技与荣誉，建材归商队。所以它是「攒下的余货换一笔好价钱」，不是新的资源来源。

商队仍然是最赚钱的一条路。大单的价值在于：商队要装货、要等返程，而大单是就地交付，适合手上正好有一批成品、又想立刻换成金币的时候。

## 成就

「成长」面板里的「成就」页签记录走过的每一步：收成、订单、商队、修缮、科技、人口、园艺、土地、装饰、建设计划等，分田园、小镇、产业、往来、生活五类，共 26 项。

成就是自动达成的，不用点领取，也不会错过——奖励是声望，可以直接拿去研究科技。已达成的那张卡片会变成暖黄色并打上勾，未达成的那张会显示进度（例如「0 / 200」），让你知道还差多少。

## 一天是怎么过的

小镇有自己的一天，90 秒一轮（和口粮、税收结算的「一天」是同一个长度），HUD 右上角会显示「第 N 天 HH:MM」，旁边写着现在是什么时段。新开的小镇从 06:00 开始，也就是上工的时间——你打开游戏时，街上已经在忙了。

- **夜里**（00:00–05:00）：大家都歇下了，作坊不开工。
- **清晨**（05:00 起）：街上刚醒，作坊陆续生火。
- **白天**（06:00–20:00）：作坊开着，有工作的居民会沿道路走去自己上班的作坊，到了就干活。
- **傍晚**（20:00 起）：收工了，人们顺着路回家。

你不需要管这件事，它自己会走。看街上的居民就能知道现在几点：白天他们聚在作坊，傍晚往家走。镇上也有一小半人不上班——孩子、老人、来串门的，所以任何时段街上都不冷清。

## 居民的需求

「居民」面板中间那几条就是居民现在的日子过得怎么样，从 0% 到 100%：

| 需求 | 靠什么提高 |
| --- | --- |
| 食物 | 仓库里的鲜鱼与面包（按三日口粮折算） |
| 饮水 | 水井、供水塔覆盖到的住宅 |
| 社区生活 | 议事厅、集市、学校、诊所、剧院等市政设施 |
| 环境 | 花园、树木、装饰，以及街区风格与邻居故事留下的永久加成 |
| 温饱 | 仓库里的**衣物** |
| 闲适 | 仓库里的**蜂蜜、奶酪、葡萄酒、陈年佳酿** |
| 信仰 | **河畔小教堂**（每级 14 户） |
| 康健 | **安心诊所**（每级 10 位） |

前四项从游戏一开始就在影响心情，也是居民愿不愿意搬来的依据。后四项是**额外的关照**：

- 每 8 位居民每天穿掉 1 件衣物，每 10 位居民每天享用 1 份闲适（不足一份按一份算）。闲适按**由廉到贵**取用，先喝蜂蜜、再吃奶酪、然后是葡萄酒，最后才动陈年佳酿——所以贵的那瓶会一直留到你真的不缺的时候。
- 备得越足，居民越满足，幸福度最多因此多 **8 点**；两条一起来算，各占一半。
- **备不齐也不会有任何惩罚**。缺衣物、缺点心的小镇，幸福度和没有这套规则时完全一样，只是少了这份加成。所以这是一条让你多一个理由去经营纺织、乳品和酿酒链的奖励，不是一道必须跨过的门槛。

温饱与闲适按三日储备折算，因此和食物一样，看到「温饱 67%」就说明手上还够两天多的量；信仰与康健按**服务了多少人**折算，所以「信仰 78%」的意思是全镇约八成人有教堂可去。

**信仰与康健做什么用**：

- 两者一起**减轻重税的代价**。税率越高，幸福度掉得越多——教堂与诊所把这份代价按覆蓋率减回去，最多减到八成，而不是清零。所以 20% 的重税不是不能走，而是要先把小镇照顾好。
- **康健还能让修缮更省**，每级诊所在满覆盖时省下约三成人工费。要注意它只减人工，材料现买的部分一分不减。
- 和温饱、闲适一样，**没有也不罚**：缺教堂、缺诊所的小镇，幸福度与修缮费和从前完全一样。

## 邻居的故事

「居民」面板里的 12 位邻居各有一段三段式的故事，讲的是他们怎么在这座小镇安顿下来。

每一段的开启都靠你**真的建了什么**：先给他们在新房子里安顿下来，等他们做事的作坊立起来，再等小镇长到一定规模。没到条件时故事就停在那里，不会消失。

每段故事你选一种做法，两个选项给的东西不一样：一种是立刻到手的货物或金币，一种是留在镇上的长期好处（永久环境加成）。两边都算数，没有会选错的选项。选完的段落会记在面板里，随时能回头看。

邻居平时说的话，提到的是**附近最近新建的那栋房子**，所以你会看见他们评论你刚盖的东西。

## 小镇荣誉

声望不只是研究的手续费。研究一共只要 52 点，而任务、里程碑、成就、街区风格和邻居故事会一直发声望，所以「科技」面板最下面有一条「小镇荣誉」，把多余的声望换成留得下的东西。

三条线，每条八级，一级比一级贵，效果永久：

| 荣誉 | 效果 | 开放等级 |
| --- | --- | --- |
| 仓廪扩建 | 仓库容量 +4／级（满级 +32） | 5 级 |
| 精工传承 | 生产时间 −1.5%／级（满级 −12%） | 6 级 |
| 安居名额 | 社区人口名额 +1／级（满级 +8） | 7 级 |

三条线都按小镇等级开放，不挑玩法——无论你走哪条路，声望都有地方可花。卡上会写着当前效果和下一级的价格，买不起时按钮是灰的。

**怎么找到它**：底部「科技」按钮在你**买得起某条荣誉时会亮起角标**（数字就是能买的条数）。打开面板后，顶部那行「已掌握 X / 8 项手艺 · 荣誉 Y / 24 级」也能看到荣誉进度，不必翻到底部。如果你把 8 项手艺都学完了，面板顶上会直接出现一条指向荣誉的提示——因为那时你大概不会再为了研究而打开这个面板了。

一级比一级贵（6 / 9 / 13 / 18 / 27 / 38 / 56 / 81），效果却是每级恒定，所以越往后每点声望买到的东西越少——这是刻意的：它让「再买一级还是留着研究」变成一个真的要想一下的问题。三条线强度相当但缓解的是不同的瓶颈（仓库常满 / 产出太慢 / 人口名额不够），所以先买哪条取决于你的小镇现在卡在哪。

## 街区风格

「成长」面板里的「街区风格」页签是三本收集册：花巷、滨河步道、工坊广场。

它不看你有多少件装饰，而是看**同一处**聚了多少件、聚得有几种。比如花巷要求在一片街角同时有花箱、花架和花树，把同一件东西堆一排是不算的。每本册子三级，一开始就能做第一级，不需要先研究什么。

风格一旦成形就永久保留——以后把花挪走也不会收回。每段风格给一份永久的环境加成，第二段会解锁一件纪念摆件（花车、野餐角、丰收堆），它们只是好看的装饰，不占工人、不产出。

## 邻居们

「居民」面板里的「邻居们」列出已经相识的邻居：每 2 位居民会介绍一位，最多 12 位。每位邻居都有立绘、住处和做事的地方。

这些信息来自小镇本身：把住处或工坊搬走、新建工坊，邻居指向的位置会跟着更新。如果某位邻居的房子受损，卡片会写「住处正在修缮，暂时借住在别处」，修好后就恢复。点「去住处」可以在地图上定位到他们家。

## 小动物

在「居民」面板可以领养橘猫或小黄狗。上限跟着人口走：每 6 位居民能多照顾一只，最多 6 只；满员时按钮会说明原因。

领养后它们不是摆设：每只小动物会认一位邻居，沿着和居民相同的路网跟在后面散步。橘猫走得慢、跟得远一些，小黄狗跑得快、贴得更近。送走最后一只可以在同一张卡片里操作。

## 商队路线

商队面板里可以选下一趟去哪里，共三条路线：

| 路线 | 货物 | 特点 |
| --- | --- | --- |
| 溪谷集落 | 面包、木板、鲜鱼 | 就在对岸，路程最短 |
| 山外集市 | 布料、衣物、工具 | 翻过山口，需研究「一针一线」 |
| 下游河港 | 葡萄酒、奶酪、蜂蜜 | 顺河而下，需研究「葡萄与酒」，带回建材最多 |

越远的路线每件货回报越高，所以要不要跑远路是一个真实的取舍。路线各自从不同的桥出镇，地图上看到的就是不同的路。选定后写入存档；商队在路上时不能改，回来领完货才能定下一趟。

### 同时派出多支商队

集市升到 2 级、3 级，以及小镇声望达到 40，都会给你多一个商队名额，最多同时派出 4 支。商队面板上会多出一排「本镇商队」，每一支都能单独选路线、单独出发、单独返程；选中哪一支，下面显示的就都是那一支的路线与货物，按钮也只会安排那一支。已经回来的那支会标成绿色并写明等你领取，不会挡住还在路上的另一支。

同一时刻可以几支都走同一条路线，路线卡片上会标出有几支正跑在这条线上。每支商队各装一份货物，所以要同时派两支，仓库里就得备两份货——名额是一回事，备得起货是另一回事。

## 季节活动（自愿）

「居民」面板里每个季节都有一场可以办的活动：春日花市、夏夜果摊、秋收宴、冬日灯火。卡片会写明需要哪些物资和金币，以及办成后幸福度加多少。

这些都是自愿的：不办不扣分、不罚款，也不会有任何损失，等下个季节还会有新活动。活动只动用富余物资——保留的建造木材和三日口粮不会被拿走；如果不够，卡片会直接标出还差多少。办成之后，议事厅旁会出现对应的摊位装饰，好心情会持续一段时间，然后自然结束。

### 常见问题

- **存档完整性校验失败**：文件可能损坏或被手动修改。请选择另一个备份；失败的读取不会覆盖原存档。
- **存档格式或版本不兼容**：请选择新版导出的 JSON。新版使用独立数据库，不会自动覆盖或迁移旧实现的存档。
- **浏览器不允许访问本地存档**：检查网站存储权限，或在普通浏览窗口中打开游戏。
- **存储空间不足**：先导出备份，再清理浏览器空间。未能完成的保存不会替换旧存档。

## 存档模块接口

模块位于 `src/save/storage.ts`，只负责保存、验证和恢复纯数据。地图渲染、离线收益结算和界面交互由对应模块处理。

| API | 行为 |
| --- | --- |
| `loadGame(slot = 'autosave')` | 返回经过完整校验的游戏状态；槽位不存在时返回 `null`；损坏或不可读时抛出中文错误 |
| `saveGame(state, slot = 'autosave')` | 原子保存快照，更新时间戳，不改变传入对象 |
| `listSaves()` | 按自动存档、槽位 1～3 的顺序返回已存在存档的时间、等级、人口 |
| `exportSave(state)` | 下载包含完整性校验的 JSON 文件 |
| `importSave(file)` | 验证文件并返回状态；不自行写库或替换当前小镇 |
| `parseSave(text)` | 解析并验证存档 JSON，便于测试或接入其他文件来源 |

合法槽位为 `autosave`、`slot-1`、`slot-2`、`slot-3`。导入大小上限为 8 MB。`loadGame` 保留存档的 `savedAt`，作为离线结算的时间锚点；调用方应在成功恢复后统一执行离线结算，避免重复发放收益。

点选非成熟的建筑可查看详情；市政厅、集市、仓库的详情提供对应管理入口与升级。生产工坊详情中的「在岗居民」可增减人手，空闲居民不足时无法继续分配。手机左侧的定位按钮可随时回到小镇中心，旋转屏幕也会重新居中。

## 2.2 · 青岚河的两岸

地图扩展为 46 × 46 格，其中 1,817 格是可建设陆地。青岚河贯穿河谷，两座桥连接两岸；北岭有陡峭山峰、矿石丘陵与林地。河道、桥梁和山峰为保留地形，不能放置建筑。

| 分区 | 规划用途 |
| --- | --- |
| 河西居民区 | 住宅、商铺与社区设施 |
| 南岸农业区 | 麦田、风车、饲料坊与牧场 |
| 河东工业区 | 木工、木炭、冶炼、铁器与纺织 |
| 北岭矿区 | 山麓矿场与采石场 |

分区是规划建议，陆地仍可自由建设。顶部（手机上为底部）的分区导航可直接移动镜头，末尾全景按钮能鸟瞰整个河谷；桌面左下角小地图显示当前位置。按 `M` 或点左侧地图按钮，查看各区建筑数量和完整地图。建造、搬迁时也可使用分区导航。

建筑详情中的「免费搬迁」允许重新选择空地，点击完成，拖动可平移地图。选择河流、桥梁、山峰或已占用地块时会提示原因，原建筑保留在原处。点取消或按 `Esc` 退出搬迁。

| --- | --- | --- |
| 田园土路 | 4 金币 | — |

居民替换为园丁、木匠、年长邻居、农人和商人等六种形象，包含不同年龄、肤色、衣着、前后朝向与交替步态。行走遵守四邻域寻路，不斜穿建筑角落；优先走道路，只通过桥梁跨河，建筑变化会触发重规划。这里展示的是居民散步与往来，不是职业产量或物流运输模拟。

地表增加草丛、裸土、沙砾、田间土色和山麓石质变化；地图外围延伸为草土地景，最小缩放时相机受到约束，避免把小镇拖出视野。
### 仓库周转与木材补货

- 仓库现在按用途展示物资，并标明“补货至”和“富余”。达到补货目标的产业会休工，消耗后自动复产，不用逐个暂停麦田。
- 老存档已积压的物资，点击仓库顶部“出售富余”即可一次换成金币、释放仓位。按钮展示本次份数与收入；正常储备、当前订单用量与全部建材包会保留。
- 点木材图标 → 查看林间木工坊，可以切换“均衡补货 / 木材优先 / 木板优先”。木材优先每轮基础产量 10，三级每轮 20；已完成的批次保持原样，收取后按新方向生产。
- 炭窑自动保留 12～60 份建造与取暖木材；显示“保留建造木材”时，收取更多木材后就会复产。面包房仍可使用燃料做口粮。
- “按需补货”控制生产，不代替在线收取。仍需点击“一键收取”，或在设置中开启市长助手。仓库不足时，先出售富余再收获；不必继续堆仓库解决同一种资源的积压。
### 集市进货

仓库面板里有一栏「集市进货」。缺料又不想等的时候，可以直接买进来——但价钱是卖出价的 **18 倍**，所以这是应急，不是生意。

能买到的是**成品**：面包、鲜鱼、工具、衣物、奶酪、蜂蜜、陈年佳酿，每次可选买 1 / 5 / 20 份。买不到建材包（那是商队存在的理由），也**买不到原料和中间品**——木材、小麦、面粉、羊毛、布料、矿石、金属锭这些都不卖。

为什么不卖原料：买进来的货如果加工后再卖，价值会被生产链放大，而**工坊升级还会让每段产出翻倍、倍数沿链条累乘**——实测 1 级放大 16.7 倍、3 级高达 266 倍。加价定得再高也挡不住这种结构性放大（要挡住得让一份小麦卖 500 金币以上，那就没意义了）。只卖没有下游消耗的成品，放大倍数恒为 1，18 倍加价就足够压过零售、商队和订单了。

所以缺原料时的正确解法是**建那座工坊**，集市的用处是「手上缺一件现成的成品，又不想等一轮生产」。

需要一座**可用的**集市才能进货；集市受损、仓库没空位、金币不够时，按钮会说明原因。

### 装饰、树木与自由搬迁

- 打开“建造 → 装饰”：原有花园之外，新增青荫橡树、春樱花树、常青松树、晚霞红枫、涟漪喷泉、听风凉亭、花畔长椅和蔷薇花拱门。它们不占工人，提供环境加成，按目录所示价格和材料建造。
- 点击左侧四向箭头“调整布局”，或按 **L**：按区域找到建筑，点击“搬迁”，再点地图空地确认。详情页名称下方也有“免费搬迁”按钮；已有产物的工坊同样可从布局列表直接搬走。
- 搬迁时原建筑变淡，预览跟随地块吸附。空地可放置；道路、其他建筑和树木、河道、桥梁与山峰会显示红色并给出原因。拖动地图可以寻找更远的位置，**Esc** 或“取消搬迁”退出，原位置保留。
- 建筑、树木与道路按地块互斥：铺路不能穿过装饰，建造和搬迁不能覆盖道路。需要改路时，先在“道路规划”移除相应路面再放置建筑。花拱门也是装饰占地，不属于可通行道路。
- 搬迁不收费用，保留等级、工人、生产方向、进度与已完成的物资，并随现有存档保存。
