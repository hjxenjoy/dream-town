# 趣味性与体验优化评审

> 2.8 方向更新：用户进一步明确希望以种田养成、自然成长为核心，减少任务和操作。当前主入口已改为田园，建设计划退为可选收藏；具体已实现内容见《13-田园养成机制》。下文保留 2.7 评审背景，不再代表当前主循环优先级。

定位：轻松经营、有目标的建设，少催促、少惩罚。本文基于当前版本文档、模拟规则与实际存档体验，不是用户群体调查；优先级属于设计判断。

## 一、从设计师与资深玩家的角度看问题

| 观察到的问题 | 设计师判断 | 玩家的感受 | 优先级 |
| --- | --- | --- | --- |
| 实测 21 级，9 项旅程全部完成；剩余指引是继续自由建设 | 新手教学结束后，成长结构断层，没有中程规划目标 | “我还能点，但不知道为什么继续点。” | P0 |
| 实测约 18 万金币、100% 幸福度；新建筑多数靠增加产量和容量区分 | 中后期数值充足，继续给金币或堆建筑难以增加满足感 | “换了一张建筑图片，做的事情差不多。” | P0 |
| 收获成熟建筑后立即打开详情 | 高频正反馈被管理面板打断，连续收获需要额外关闭操作 | “我只想把这一排收完。” | P0 |
| 工坊主要表现为静态图片、细进度条和完成勾号 | 开工、缺料、库存充足、暂停缺少直观区分 | “看不出小镇在忙什么。” | P0 |
| 所有操作使用相似音符和粒子 | 没有反馈强弱层级，建房与普通点击的情绪重量接近 | “升级了，但没感觉发生了什么。” | P1 |
| 居民是循路移动的匿名角色 | 有运动，但尚缺住所、职业、事件与玩家行动之间的关系 | “有人走来走去，但还不像我认识的邻居。” | P1 |
| 运输停留在出发、等待、领奖状态 | 运输链在数值上成立，地图叙事不完整 | “出发了，可我没看到它去哪里。” | P2 |
| 大地图有很多可用土地，区域功能仍偏自由摆放 | 美化、产业协作与地方特色尚可增强 | “地方很大，却不一定有理由走到那里。” | P2 |

核心方向：让“我想把这个地方变好”成为动机，把经营压力控制在可主动解决的范围。不能用仓库再次堵塞、更长等待、随机扣资源来替代真正的决策。

## 二、本轮已实现

### 1. 自主选择的建设计划

在旅程面板加入三条路线，每条三阶段。玩家主动选择当前计划，可以随时更换；已完成阶段永久保留，未完成阶段根据实际小镇现状重新计算。既有建筑、布局和运输成绩参与目标，不要求拆除重建来刷次数。

- **花园里的家**：住宅附近布置花木 → 学校、诊所与供水 → 60 位居民、8 处有绿意的住宅。最终称号「花园家园」，社区人口名额永久 +12。
- **河谷匠人街**：原木与锯木分工 → 三座就近配套的加工坊 → 六座配套工坊及消防覆盖。最终称号「精工之乡」，全体工坊生产时间永久减少 5%。配套按“5 格内存在产出所需原料的建筑”判定，每座加工坊只计一次；**这条判定现在同时也是真实的经营加成**：配套的加工坊每轮生产时间最多减少一成，按**居民实际要走几格**分级（贴邻居满额、6 格归零），见《19》2.5.1 与 2.5.2。仍未实现的是实际货运与居民通勤加成。
- **丰收与远方**：麦田、磨坊、面包房 → 养鱼与三天口粮 → 45 位居民与累计 20 次商队返程。最终称号「丰收之港」，商队旅程永久缩短 10%。

阶段奖励提供少量经验与声望，最终奖励改变后续经营。各阶段有明确筹备物资，点击落成才交付；保留建造木材，涉及食品时交付后需剩余三天口粮。没有倒计时、失败罚款、每日重置或强制连续登录。副官与离线结算不会替玩家交付计划。

### 2. 操作与反馈分层

- 点成熟建筑：收取成功后留在地图，继续点下一处；再次点建筑可进入管理。收取失败仍可进入详情处理。
- 资源到账：根据实际库存与金币增量飞入仓库或金币栏，最多展示三枚资源提示，完整数量保留在收获回执；限制造成的屏幕堆积。
- 建造、升级、搬迁、收获：分别使用轻落成、回弹与短提示。新建成功后留在地图欣赏结果，点建筑可管理。
- 计划落成、升级小镇、庆典：提供明显的庆祝提示；普通选择与设置不再撒同样的金色粒子。
- 收获、建造、计划落成使用不同音符组合，仍受音效设置控制。

### 3. 地图状态动画

- 通过实际生产进度变化判断是否开工；暂停、缺料、已收满、受损时不播放工作烟雾和加工火花。
- 热加工工坊有轻烟，其他加工坊有工作火花；井、喷泉、供水塔和工作中的渔业建筑有水波；成熟标记轻浮动。
- 庆典期间议事厅附近出现彩纸；这些动画只表达状态，不额外产生资源或改变模拟速度。
- 增加持久化的「轻量动画」偏好，未设置时跟随系统减少动态效果偏好。资源数值和文字提示保留。
- 环境效果共用 Graphics，最多同时绘制 30 个视口内设施的效果；不为每个工坊建立常驻粒子发射器。

## 四、如何判断是否更好玩

以下为后续试玩目标，不冒充已经取得的用户数据：

- 玩家回到小镇后 30 秒内能说出自己这次想完成的目标。
- 收一排成熟建筑不再频繁开关面板；高频操作保持可连续进行。
- 不看详情，也能区分工作、成熟和安静的生产区。
- 一次约 10–20 分钟的游玩，至少有一次有意义的布局改善或建设阶段进展，而不只是库存增加。
- 花木布局、人口增长和产业配套至少各有一种能被玩家解释的收益。
- 轻量动画开启后仍能完成全部操作，数值规则与奖励完全相同。

首批效果需要继续通过实际游玩判断，特别是后两阶段的人口目标和材料成本。若出现“为了做任务机械摆建筑”，应增加替代达成路径与居民故事，而不是继续提高数量门槛。
