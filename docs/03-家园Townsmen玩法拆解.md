# 03 · 家园 (Townsmen) 玩法拆解

## 1. 核心循环

```
建房 → 居民入住 → 居民有需求(食物/饮水/衣物/娱乐/信仰/医疗)
  → 需求满足 → 幸福度↑ → 可提高税率 → 税收↑
  → 资金 → 扩建生产链/更多房屋 → 更多居民(人头税) → 税收↑↑
```

与 Township 的根本差异：**居民是经济引擎**。每个居民既消耗物资又缴纳人头税，经营的本质是"让每个居民的净贡献为正"。攻略核心口诀：**食物足、房子多、收入多**。

## 2. 建筑体系（按功能分类）

### 市政
- **市政厅 (Town Hall)**：核心建筑，收税、任务发布、科技/声望管理的中心。
- **市场 (Market)**：资源交易枢纽，连接生产与贸易；可购买稀缺工具（锯子/工具/项链），出售富余物资。攻略建议"屯资源换工具"。

### 住房
- 民居分多个等级（1→3 级可升级/重建），等级越高容纳人口越多、税收越高。中期攻略共识：**炸掉 1 级民居全换 3 级**。

### 资源采集
| 建筑 | 产出 | 备注 |
| :--- | :--- | :--- |
| 伐木场 + 锯木厂 | 原木 → 木板 | 木材是第一硬通货，建造/燃料都要 |
| 渔屋 | 鱼 | 成本极低（10 木 + 100 金），**不受季节影响、取之不尽**，前期粮食主力 |
| 猎人屋 | 皮毛/肉 | ⚠️ 猎区鸟兽会**灭绝**，还会触发瘟疫，前期陷阱建筑 |
| 采石场 | 石料 | 中后期建造材料 |
| 矿场（金/银/铜） | 矿石 | ⚠️ 矿脉**会枯竭**；冶炼还需木炭，前期人力金钱消耗大，慎入 |

### 农业与食品链
- 农场（小麦）→ 磨坊（面粉）→ **面包房（面包）**——经典三级食品链。
- 牧场：养羊（羊毛）、养猪（卖钱/后期香肠）。
- 药草园：草药（医疗/酿酒原料）。
- 后期：**葡萄园 → 酿酒厂**、啤酒花 → 啤酒（酒馆消费品）。

### 手工业
- 纺织厂 + **裁缝铺**：羊毛 → 布料 → 衣物（居民穿衣需求 + 高价商品）。
- **铁匠铺**：打造工具/武器/盔甲（士兵装备的前置），耗木/炭量大，旁边须配伐木小屋。
- 炭窑：原木 → 木炭（冶炼/铁匠燃料）。

### 民生服务（满足需求、提升幸福度）
- 水井（饮水）、**酒馆**（娱乐+啤酒/香肠消费）、**教堂**（信仰）、**医馆**（医疗/防疫）、娱乐场/马戏团。

### 防御与应急
| 建筑 | 作用 |
| :--- | :--- |
| 消防塔/水井网络 | 覆盖范围内扑灭**火灾**（核心覆盖机制） |
| 兵营 + 岗哨 | 训练士兵、巡逻抵御**强盗入侵**；⚠️ 前期是大坑：兵营 1500 金 + 岗哨 350 金，士兵没武器盔甲啤酒香肠时战力为零 |
| 城墙/城堡 | 后期防御升级 |

## 3. 居民需求与幸福度

- 需求分层递进：食物/饮水（生存）→ 衣物（温饱）→ 娱乐/酒馆（小康）→ 信仰/医疗（富足）。
- **幸福度**由需求满足率、税率、灾害损失综合决定；幸福度是收税的前提——"只要有粮食就不掉满足感，就能拉高税收"。
- 幸福度高的表现：居民走动勤快、节日庆典；低的表现：抱怨、罢工、搬离。
- 细节设计：每个建筑有专属音效（市场喧闹声、葡萄酒厂踩葡萄声），居民是**可观察的个体**（上下班、看马戏、罢工抗议），强盗会大摇大摆进村与守卫决斗。

## 4. 税收经济

- 主要收入 = **人头税**（按居民计）+ 商品销售（面包/衣物/香肠等高附加值品）。
- 税率可调：粮食充足、需求满足时提高税率增收；资源短缺期必须降税保幸福度，否则人口流失。
- 声望 (Prestige)：完成任务获得，用于解锁新建筑/科技/剧情章节。

## 5. 季节与灾害系统

### 四季
春夏秋冬循环，**影响农业产出**（冬季农田休耕/减产），渔业与林业全年稳定——这是攻略推荐"鱼+木开局"的根本原因。

### 灾害（随机事件，提供经营张力）
| 灾害 | 应对 |
| :--- | :--- |
| 火灾 | 建筑连环起火，靠消防塔覆盖扑灭；布局第一课就是防火分区 |
| 瘟疫 | 人口/粮食锐减，医馆救治；猎人屋过度捕猎会诱发 |
| 旱灾 | 农业减产，考验粮食储备 |
| 强盗入侵 | 偷物资（鱼/木板/小麦/羊毛）、烧房子；兵营岗哨抵御，前期裸奔靠消防止损 |

## 6. 布局策略（社区共识）

Townsmen 与 Township 最大的机制差异：**布局有真实代价与收益**。

1. **前期密集型**：资源紧张时所有建筑集中放置，消防/岗哨一次覆盖全区。
2. **后期功能分区**（资源充裕后重拆重建）：
   - 南面住宅区、北面庄园农业区、西面工商业区；
   - 四角各设消防塔 + 岗哨形成覆盖网。
3. 省成本技巧：前期尽量**不修路**（先把房子规划好，后期补路）；酒馆等需求建筑放城镇边缘（不需防御，配一座防火塔即可）；生产建筑旁配建原料建筑（铁匠铺旁配伐木小屋）。

## 7. 攻略流派：农业致富流（TapTap 精华帖）

作者全程放弃工业，验证了经济系统的弹性：

```
前期：3 渔屋(不升级) + 2 伐木场 + 1 锯木厂 + 1 消防 + 1 铜矿 + 1 市场
      + 1 农场(小麦→面粉→面包) + 1 农场(羊毛→纺织→裁缝) + 1 猪场
中期：民居全升 3 级，补医馆/兵营/酒馆/娱乐场，卖面包衣物换金、市场买工具、做任务攒声望
后期：葡萄园/啤酒园/教堂
成果：70+ 人口小镇，满足度 200，资金富裕，零工业污染
```

**设计启示**：生产链要允许多种"通关流派"（农业流/工业流/贸易流），单一路径强制是最差设计。
