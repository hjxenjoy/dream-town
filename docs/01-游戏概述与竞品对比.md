# 01 · 游戏概述与竞品对比

## 1. 两款对标游戏定位

### 梦想小镇 (Township, Playrix, 2011/2012)

- **品类**：休闲农场 + 城镇建造 + 订单经营的混合体（Farm-City Builder）。
- **核心目标**：将单一农业经营串联成完整产业链，赚取收入、扩张领土、建设房屋/社区建筑/工厂。
- **时间模型**：与真实时间同步（real-time），种植/生产需要真实等待，可用付费货币（绿钞 Township Cash）加速。
- **节奏特征**：碎片化打卡式（收菜→排产→交订单→下线），依赖每日奖励（Daily Bonus）、合作社/赛舟会等社交机制留存。
- **商业表现**：2021 年累计下载超 2.48 亿，是 Playrix 起家的第一款手游，长期位居 50+ 国家畅销榜前列。

### 家园 (Townsmen, HandyGames, 系列自 2004 塞班时代起)

- **品类**：中世纪题材的沙盒式城镇建造（City Builder），人称"口袋里的模拟城市"。
- **核心目标**：从小村庄发展为城镇——建房屋吸纳居民、建生产建筑形成产业链、靠税收获取资金循环扩张。
- **时间模型**：游戏内时间连续流逝（可暂停/加速），有**四季更替**影响农业产出。
- **节奏特征**：连续经营式，玩家持续在场调度；核心张力来自**居民需求满足 → 幸福度 → 税率 → 收入**的动态平衡，以及火灾/瘟疫/旱灾/强盗入侵等**随机灾害**的应急处理。
- **特色细节**：每个建筑有独立音效与动画，居民是可观察的个体（上下班、看马戏、抱怨罢工），沉浸感极强。

## 2. 核心差异对比

| 维度 | 梦想小镇 Township | 家园 Townsmen |
| :--- | :--- | :--- |
| 题材 | 现代田园 + 工业链 | 中世纪村庄 |
| 驱动力 | 订单/运输（直升机、火车、飞机、船） | 居民需求 + 税收经济 |
| 布局重要性 | **低**（官方明确：城镇规划对结果影响很小） | **高**（消防/岗哨覆盖范围、产区划分决定成败） |
| 资源压力点 | 仓库容量（Barn） | 粮食供给 + 资金链 |
| 随机性 | 低（订单内容随机） | 高（火灾/瘟疫/强盗/旱灾） |
| 货币 | 金币 + 绿钞（双货币） | 单一金币（税款） |
| 时间 | 真实时间等待 | 游戏内时间，可加速 |
| 社交 | 合作社/赛舟会/好友互助 | 纯单机 |
| 离线 | 在线为主（需联网同步） | 天然单机离线 |

## 3. 本项目（梦幻家园）的取舍

本项目是 **Web 端纯离线单机** 游戏，因此：

| 取舍项 | 决定 | 理由 |
| :--- | :--- | :--- |
| 总体骨架 | **以 Townsmen 为骨架**（建造+居民+税收+灾害） | 单机离线属性天然契合；无社交/内购依赖 |
| 经济循环 | **吸收 Township 的生产链与订单/运输系统** | 提供明确的"下一步做什么"目标感，缓解沙盒无目标问题 |
| 时间模型 | 游戏内时间 + 离线收益结算 | 离线游戏不能做真实时间强制等待，但保留"运输周期"等软等待 |
| 布局 | 保留 Townsmen 的覆盖范围机制（消防/哨塔/市场） | 增加布局决策深度，是 Townsmen 区别于 Township 的核心乐趣 |
| 社交/内购 | 全部移除，改为单机成就与声望 | 本地离线定位 |
| 灾害系统 | 保留（火灾/旱灾/强盗），做成可调难度开关 | 提供经营张力与重玩价值 |

**一句话定位**：有 Township 式生产链和订单目标感的、单机离线版 Townsmen。
