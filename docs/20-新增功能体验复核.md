# 新增功能体验复核 · 2026-09-12

本轮检查新增素材的渲染接入、居民与故事面板、季节活动、资源买入和库存保护，并运行现有模拟层回归测试。方向继续采用轻松种田养成：让已有系统表现清楚，不增加必须处理的任务。

## 已修正

- 居民劳作：原来只有行走才会切换动作帧，驻足工作一直显示第零帧；现在工作也循环两帧，站立时不产生走路起伏。
- 减少动画：居民、搬运工和宠物停止装饰性换帧，居民停止起伏及搬迁淡入；寻路仍照常运行。暂停也停止动作帧。
- 季节摆件：活动不变时也更新议事厅对应的位置，读取另一份布局或移动议事厅后不会留在原地；找不到议事厅时隐藏。
- 邻居故事：部分故事已完成但后续未解锁时，显示实际回忆数量，不再误报三段全部完成。
- 职业说明：缺少本职建筑时明确显示临时帮工及期待的建筑，不再把磨坊误写成医生、老师的正式工作地点。
- 民生读数：衣物满足度改称“衣着”，避免与食物“温饱”混淆。

## 验证与边界

- 修改前全套 332 项测试通过；新增两项动作行为回归测试，覆盖驻足工作、闲置、暂停与减少动画。修改后全套 334 项通过，0 失败。
- TypeScript、生产构建、离线缓存检查通过；离线清单 57 个资源，约 23.53 MB。
- 浏览器从既有 23 级小镇进入，完成正常离线结算；主界面、居民面板及地图渲染正常，检查时控制台无 error。首次载入仍使用旧 Service Worker，离开页面再进入后验证到本轮生产脚本。
- 没有清空存档或注入测试资源。季节搬迁与故事中间阶段修复依据明确的控制流缺陷，未在玩家存档上强制制造这些状态。
- 这次未重新标定长时经济曲线，也未完成所有季节、机械与移动设备的逐帧视觉验收。现有素材的边缘裁切、机械锚点仍需按真实画面逐项精修；静态比例测试不能替代它们。
