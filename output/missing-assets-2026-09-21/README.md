## 查看与复现

- 运行 `npm run dev`，打开 `/asset-preview.html`，选择“本次新增 · 80 帧”或“环境音试听”。
- `.venv/bin/python scripts/catalog-missing-assets.py`：从保留的 PNG 重建无损 WebP 与索引，依赖 Pillow、NumPy。
- `.venv/bin/python scripts/generate-building-ambience.py`：固定随机种子重建音频，依赖 NumPy。
- `npm run build`：TypeScript、构建、离线资源与新增目录校验。

## 验收与接入边界

- 80 个帧矩形均在图集内；Alpha > 32 的像素不触碰分格边界。
- WebP 无损保存可见像素和完整 Alpha，原始图片没有重绘或缩放。
- 天气、军事、动物园曾因间距不足重新生成，交付目录仅保留最终选定版。
- 20 条 WAV 均为 22050 Hz、16-bit、单声道、8 秒；无削波，循环首尾采样值一致。
- 帧锚点是建议值，放入场景时仍需按建筑尺寸和落点校准；光标热点同样需校准。
- 面板为空白美术底板，文字、按钮、可访问性语义由代码绘制；活动摘要面板用于可见的任务状态与执行记录。
- 本批是静态素材，不含人物/动物行走帧、车辆多方向帧、城墙自动拼接规则或作物生长动画。
- 新素材已接入素材册和离线资源清单，尚未注册为游戏中的可建造建筑或启用对应玩法；目录明确标记 `runtimeIntegrated: false`。
- 音频是风格化合成素材，非实地录音，尚未接入场景距离混音。
